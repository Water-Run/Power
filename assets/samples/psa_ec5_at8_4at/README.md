# PSA EC5 + AT8 4AT 完整动力总成样例

状态：资料与资产骨架；尚不是可发布的标定资产  
资产 ID：`power.sample.psa_ec5_at8_4at`  
证据清单：[source_manifest.toml](source_manifest.toml)

## 1. 目标与配置边界

本样例建立可被游戏嵌入、可回放、可验证的前置横置前驱完整动力总成，而不是把一张发动机扭矩曲线连接到理想四挡开关。边界从空气、燃油、12 V 供电、驾驶员命令和车辆网络开始，经 EC5 发动机、ECU、驱动盘/变矩器、AT8 四挡液力自动变速器、TCU/液压控制、主减速器与差速器，到左右半轴；排气从排气门一直计算到尾管环境边界。

目前采用雪铁龙 2012 年 C-Elysée 技术培训资料 `C_15473` 中的 `EC5 115 Ch + AT8 四挡自动` 作为候选集成基线。该资料能证明这套组合存在，但还不能唯一确定市场、工厂、发动机完整型式、变速器铭牌、排放包或软件版本。因此：

- 在取得供体 VIN、DAM/OPR、发动机和变速器标牌、零件号、ECU/TCU 标识及排放随车资料前，候选基线保持 `provisional`；
- `115 Ch` 只保留为原培训资料中的版本描述，不在缺少额定转速、测量标准和供体身份时擅自换算成发布标定；
- Peugeot Citroën Moteurs 的 EC5 Flex Fuel L6 技术表是 E22/E100 燃料版本，不能把它的功率、扭矩、压缩比、控制器或热限值直接复制给本候选版本；
- 后期官方资料也存在 `EC5 + EAT6` 组合，说明 `EC5` 名称本身不能决定变速器、市场标定或排放配置；
- 本文件中的 `AT8` 明确指 PSA 资料所列的四个前进挡 BVA AT8，不是后来的八挡 `EAT8`；
- 任何缺少直接适用证据的数据均保留为 `needs_verification`，不以 AL4、TU5 或其他 EC5 版本的常见数值填空。

## 2. 证据等级

| 标记 | 含义 | 可否进入发布标定 |
|---|---|---|
| `confirmed` | 在声明的车型、版本或家族范围内由 OEM/技术培训资料直接支持 | 可以，但必须同时保留适用范围和版本限制 |

| `provisional` | Power! 的候选集成或模型策略，不是 OEM 事实 | 只可用于研发，并在能力查询和结果元数据中持续可见 |

## 4. 共同完整动力总成系统边界

共同边界契约 `power.complete_powertrain.v1`：本样例与 [EA211 DJS + DQ200](../ea211_djs_dq200/README.md) 都从空气/环境、燃油、12 V 供电、驾驶员命令和车辆网络输入开始，覆盖发动机、进排气与排放、热/润滑/附件、电子控制、发动机至变速器耦合、变速器、主减速器、差速器和左右半轴，并以半轴机械输出、尾管排放、热/电负载、诊断与声振事件为输出；轮胎、制动器、车身和道路负载只作为宿主边界。两样例的差别只能是部件拓扑、参数和控制策略，不能通过删除电子控制、排气后处理、热系统或终传动来缩小“完整动力总成”的含义。

```text
空气/环境 ─┐
燃油箱/蒸发 ├─> 进气/节气门 ─> EC5 气缸/曲轴系 ─> 驱动盘
12 V 电源 ──┤          │             │                 │
驾驶员命令 ─┤          │             ├─ 冷却/润滑/附件 v
车辆总线 ───┘       ECU/传感器/执行器             液力变矩器
                                                    │  └─ 锁止支路参数待核实
排气门 -> 歧管 -> 后处理 -> 消声器 -> 尾管       AT8 四挡机构
                                                    │
热量 -> 冷却液/机油/ATF/壳体/环境        主减速器/差速器
                                                    │
                                         左右半轴 -> 车轮侧负载边界
```

样例必须包含以下动态子系统，缺失者不能标记为“完整动力总成”：

1. **发动机本体**：四缸曲轴角状态、曲柄连杆惯量与摩擦、配气、气缸充量、燃烧/失火/爆震约束、泵气损失和缸壁传热。
2. **进气、燃油与点火**：空气滤清器、节气门、歧管容积、低压供油、喷油器动态、燃油/蒸发边界、点火线圈和逐缸命令；不得从 Flex Fuel 或 TU5 资料猜本供体的燃油模型。
3. **排气与排放**：排气门、歧管、前后排气管、催化器、氧传感器、消声容积和尾管；背压必须反馈到换气和泵气功，并保存组分质量与热状态。
4. **热与流体**：缸体/缸盖/活塞/排气后处理热节点，冷却液和机油回路，以及 ATF、油泵、液压块、变矩器和换热器热状态；支持冷起动、热浸和停机后演化。
5. **低压电气与电子控制**：12 V 电池、起动机、发电机和附件负载；ECU/TCU/BSI/ABS 交互、任务周期、网络延迟、采样/量化、执行器限制、欠压复位、诊断和降级。
6. **液力与扭转机械链**：曲轴/驱动盘、变矩器泵轮/涡轮/导轮及锁止支路、输入轴、行星机构、摩擦元件、降速齿轮、输出轴、主减速器、差速器和半轴；保存惯量、滑差、柔度、阻尼、间隙和损耗。
7. **AT8 液压控制**：机械油泵、压力调节、液压块/阀体、电磁阀、E1/E2 和 F1/F2/F3 执行压力、润滑与冷却流量、油温/压力/转速/挡位传感器、适应值和故障状态。
8. **整车耦合边界**：选挡、制动/油门、轮速、坡度、道路负载和车身惯量由宿主提供；Power! 输出左右半轴扭矩、尾气、热量、电负载、振动/声学事件和诊断。

空调压缩机、助力泵等附件可由宿主开关，但其轴功率或电功率不能消失。轮胎与车身空气动力学不属于资产内部，可作为参考车辆场景的外部模型存在。

## 5. AT8 四挡液力自动拓扑与 AL4 谱系

证据不支持把 `AT8` 简单写成“换名的 AL4”。较准确的当前结论是：Citroën 技术材料把 AT8 描述为 AL4 的替代演化，并明确提到变矩器和管理软件变化；另一份同时标为 `AL4/AT8` 的售后培训资料给出共同机构图和摩擦元件作用表。因此，Power! 可以共享家族级拓扑接口，但不能共享未经核验的零件参数、压力、油液、齿数、齿比或换挡标定。

```text
EC5 曲轴 -> 驱动盘 -> 液力变矩器 -> 涡轮/输入轴
                         └─ 锁止离合支路（存在性细节和控制域待供体确认）
                                      │
                                      v
                         两组耦合行星齿轮机构
                         ├─ E1 / E2 多片离合器
                         ├─ F1 盘式制动器
                         └─ F2 / F3 带式制动器
                                      │
                              中央降速齿轮/输出轴
                                      │
                              主减速器/差速器
                                      │
                                 左、右半轴

发动机驱动油泵 -> 压力调节/液压块/电磁阀 -> 变矩器与 E/F 摩擦元件
ECU <-> TCU/变速器 ECU <-> 选挡、制动、轮速、仪表与诊断网络
ATF -> 变矩器/轴承/摩擦元件/阀体 -> 换热器 -> 冷却与环境热边界
```

家族级摩擦元件作用表如下，未填任何逐挡齿比：

| 状态 | 接合元件 | 证据范围 |
|---|---|---|
| R | E1 + F2 | `AL4/AT8` 售后培训资料 |
| 1 | E1 + F3 | 同上 |
| 2 | E2 + F3 | 同上 |
| 3 | E1 + E2 | 同上 |
| 4 | E2 + F1 | 同上 |

换挡必须由变矩器滑差/锁止、油泵流量与主压力、阀动态、摩擦元件充油和扭矩交接、行星排及轴系动态共同产生。禁止把 AT8 模拟成无液压、无热状态、无换挡瞬态的理想齿比开关。

## 6. 待核实参数

以下数据当前不得填入发布资产：

- **供体身份**：完整 VIN、DAM/OPR、车型项目/市场代码、发动机完整型式与序列号、AT8 铭牌/制造号、生产日期、排放阶段、轮胎滚动半径；
- **EC5 版本**：供体是否对应 `115 Ch` 培训版本、燃料规格、额定功率/扭矩及转速、排量、缸径/行程、压缩比、气缸盖/凸轮/活塞修订；
- **发动机几何与惯量**：连杆、燃烧室、气门、曲轴/驱动盘/附件惯量与质量、扭转刚度、摩擦和泵气；
- **配气与流量**：气门升程/持续角/相位范围、端口流量系数、歧管容积、漏气和残余废气；
- **燃烧与燃油**：逐缸压力、燃烧持续期、循环波动、爆震边界、喷油器流量/延迟/压力、燃油低位热值/蒸发/组分；
- **ECU 与电子**：供体 ECU 型号、任务周期、扭矩结构、节气门/点火/喷油/怠速/保护闭环、BSI/ABS/TCU 信号、诊断和降级；
- **排气/后处理**：确切歧管、催化器、氧传感器和消声器拓扑，容积、流阻、储氧/转化及热参数；
- **冷却/润滑/附件**：回路拓扑、泵图、节温器、热容/导热/换热、油压/油温依赖摩擦、起动机/发电机/空调和助力负载；
- **AT8 身份和传动比**：完整变速器型式/制造号、四个前进挡与倒挡齿比、降速比、主减速比和差速器/半轴版本；
- **变矩器**：泵轮/涡轮/导轮几何、容量因子与扭矩比曲线、导轮单向离合器、锁止离合器结构/摩擦/热特性及作用范围；
- **行星与摩擦元件**：AT8 供体的齿数与连接复核、轴/齿轮/差速器惯量和效率、E1/E2/F1/F2/F3 容量、间隙、摩擦、回位和热参数；
- **液压与 ATF**：油液规范/容量、油泵排量与效率、主压力、阀流量、蓄压/泄漏、充油时间、换热器和温黏特性；
- **TCU/变速器 ECU**：硬件/软件号、换挡/锁止/爬行/保护/故障策略、适应值、发动机扭矩干预握手、报文 ID/缩放/周期/超时；
- **声振**：燃烧激励、变矩器与锁止抖动、行星/降速齿轮啮合、半轴扭振、壳体/悬置传递函数和安装点振动。

AL4 培训手册中的齿数、齿比、锁止挡位、油量和压力不得自动用于 AT8；网上常见的“301 齿比表”也不得作为本资产默认值。

## 7. 所需测量数据

### 7.1 身份与静态拆检

- 记录 VIN、DAM/OPR、发动机/变速器/ECU/TCU/催化器/氧传感器零件号、标牌和软件版本；
- 实测 1–4、R、降速齿轮及主减速输入输出转数比，记录差速器和半轴结构；
- 复核变矩器、两组行星排、E1/E2、F1/F2/F3、油泵、阀体和换热器真实连接；
- 三维测量气道、排气管路和液压关键容积，并称量/摆测转动件惯量。

### 7.2 发动机台架

- 在稳定转速/负荷网格采集轴端扭矩、空气/燃油流量、歧管压力/温度、lambda、点火和喷油；
- 采集拖动摩擦图、泵气回路和附件分项功率；
- 以曲轴角同步采集逐缸压力、进排气压力、喷油/点火和瞬时转速，覆盖冷机、暖机、稳态和瞬态；
- 采集冷却液/机油流量、压力、温度和热拒绝，辨识冷起动、热平衡和停机热浸。

### 7.3 排气与排放

- 同步测量发动机出口、催化器前后和尾管压力、温度、质量流与 lambda；
- 测量 engine-out 与 tailpipe 的 CO、CO2、HC、NOx、O2 及适用颗粒指标，保存仪器延迟和采样管动态；
- 进行冷起动、富/稀切换、失火、减速断油和热浸再起动，辨识 light-off、储氧、转化效率、压降和热参数。

### 7.4 AT8 与集成台架

- 同步采集发动机、变矩器涡轮/输入、输出和轮速，半轴扭矩，选挡、实际挡位、E/F 命令、主压力、油温和电磁阀状态；
- 在受控输入转速和扭矩下辨识变矩器容量因子、扭矩比、导轮状态、锁止滑差/摩擦和热模型；
- 覆盖起步/爬行、全部升降挡、制动降挡、坡起、反复换向、低温/高温、热保护和液压/传感器故障；
- 以压力传感器和高速转速/扭矩测量辨识摩擦元件充油、接合、扭矩交接、换挡孔/峰、效率、间隙和半轴扭振；
- 记录 ECU/TCU/BSI/ABS 的硬件时间同步总线数据，特别是驾驶员需求、允许/实际发动机扭矩、挡位阶段、锁止与扭矩干预。

所有原始数据都需保存设备、校准证书、采样率、滤波、时间基准、环境和不确定度；处理曲线必须可追溯到原始通道，不能只保留截图。

## 8. 验证与发布门槛

1. **身份冻结**：供体、EC5 完整版本、AT8 制造号、市场/排放包和软件版本全部确定；
2. **部件级**：发动机气路/燃烧/热账本、变矩器、行星排、摩擦元件和液压试验分别通过；
3. **台架级**：发动机稳态/瞬态、起步/锁止/换挡/热保护与实测数据在声明误差内；
4. **整机级**：ECU—TCU 扭矩握手、背压、12 V 功耗、冷起动后处理、ATF 热状态和半轴输出形成同一闭环；
5. **游戏级**：固定步长下确定性回放，多精度档误差有报告，宿主 FPS/音频/渲染开关不改变物理 hash；
6. **故障级**：传感器偏置/掉线、总线超时、欠压、失火、排气堵塞、锁止抖动、ATF 过热和液压不足均有可复现后果与诊断。

完成这些门槛前，样例名称后应展示 `Research / Unverified calibration`，不得宣传为 EC5/AT8 数字孪生。
