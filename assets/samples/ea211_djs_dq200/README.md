# EA211 DJS + DQ200 完整动力总成样例

状态：资料与资产骨架；尚不是可发布的标定资产  
资产 ID：`power.sample.ea211_djs_dq200`  
证据清单：[source_manifest.toml](source_manifest.toml)

## 1. 目标与配置边界

本样例的目标不是“给一个发动机扭矩表再串一个七挡变速器”，而是建立可被游戏嵌入、可回放、可验证的前置横置前驱完整动力总成：从空气、燃油、12 V 供电和驾驶员命令边界开始，经发动机、ECU、双质量飞轮、DQ200 双干式离合变速器、TCU/机电控制单元、主减速器与差速器，到左右半轴输出；排气从排气门一直计算到尾管环境边界。

官方资料证明 `DJS + DQ200` 存在，但它仍不是唯一硬件配置。上汽大众 VIN 规则列出了 DJS 与 `0CW.C`、`0CW.M`、`0CW.P` 等 DQ200 变体的组合，不同车型还可能使用不同排放包、主减速器、软件和附件。因此：

- 暂以 2019 款上汽大众 T-Cross/途铠 `SVW64010DT`、`DJS (04E.H) + DQ200 (0CW.C)` 作为候选集成基线；
- 在取得供体车辆 VIN/PR 码、变速器铭牌和排放随车清单前，不冻结齿比、主减速比、后处理拓扑或 ECU/TCU 标定；
- EA211 家族资料只能决定待建模的结构和测量计划，不能覆盖 DJS 专属参数；
- 任何暂缺数据的组件都必须标为 `unverified` 或 `provisional`，不能用无来源数值冒充实车。

## 4. 完整动力总成系统边界

共同边界契约 `power.complete_powertrain.v1`：本样例与 [PSA EC5 + AT8 4AT](../psa_ec5_at8_4at/README.md) 都从空气/环境、燃油、12 V 供电、驾驶员命令和车辆网络输入开始，覆盖发动机、进排气与排放、热/润滑/附件、电子控制、发动机至变速器耦合、变速器、主减速器、差速器和左右半轴，并以半轴机械输出、尾管排放、热/电负载、诊断与声振事件为输出；轮胎、制动器、车身和道路负载只作为宿主边界。两样例的差别只能是部件拓扑、参数和控制策略，不能通过删除电子控制、排气后处理、热系统或终传动来缩小“完整动力总成”的含义。

```text
空气/环境 ─┐
燃油箱/蒸发 ├─> 进气与增压 ─> DJS 气缸/曲轴系 ─> 双质量飞轮
12 V 电源 ──┤          │          │                    │
驾驶员命令 ─┤          │          ├─ 冷却/润滑/附件    v
车辆总线 ───┘       ECU/传感器/执行器          DQ200 双干式离合
                             │                K1 / K2 + 齿轮组
排气门 -> 涡轮/管路 -> 后处理 -> 消声器 -> 尾管     │
                             │          主减速器/差速器
热量 -> 冷却液/机油/壳体/环境                      │
                                      左右半轴 -> 车轮侧负载边界
```

样例必须包含以下动态子系统，缺失者不能标记为“完整动力总成”：

1. **发动机本体**：四缸曲轴角状态、曲柄连杆惯量与摩擦、配气正时、气缸充量、燃烧/失火/爆震约束、泵气损失和缸壁传热。
2. **进气与增压**：空气滤清器、节气门、进气容积/可变进气路径、压气机、中冷器、增压执行器及其压力、温度和流量状态。
3. **燃油与点火**：油箱/蒸发边界、低压与高压供油、喷油器动态、燃油性质、线圈/火花塞和逐缸点火命令。
4. **排气与排放**：排气门、歧管或缸盖内通道、涡轮、前后排气管、催化器、可能的颗粒过滤器、氧传感器、消声容积和尾管；必须把背压反馈到换气与泵气功，并保存组分质量和热状态。
5. **热与流体**：缸体/缸盖/活塞/涡轮/排气后处理热节点，冷却液回路、节温器/水泵、机油回路及环境换热；支持冷起动、热浸和停机后状态。
6. **低压电气与电子控制**：12 V 电池、起动机、发电机和附件负载；ECU/TCU 任务周期、CAN 通信、传感器采样/量化/延迟、执行器饱和/速率、欠压复位、诊断和降级。
7. **扭转机械链**：曲轴、双质量飞轮、K1/K2、两根输入轴、三根输出轴、同步器/选挡机构、主减速器、差速器与左右半轴；各节点具有惯量、柔度、阻尼、间隙和损耗。
8. **DQ200 机电液控制**：电动液压泵、蓄压器、压力动态、电磁阀、离合器与选挡执行器、位置/转速/压力/温度传感器、离合器接合点自学习和故障状态。
9. **整车耦合边界**：挡位选择、制动/油门、轮速、坡度/道路负载和车身惯量由宿主或车辆模型提供；Power! 输出左右半轴扭矩、尾气、热量、振动/声学事件和诊断。

空调压缩机、真空/制动相关负载等附件可由宿主开关，但其机械或电气功率不能被忽略。轮胎与车身空气动力学不属于本资产内部，可作为官方参考车辆场景的外部模型存在。

## 5. DQ200 双干式离合与奇偶轴拓扑

大众自学手册 390 给出的 DQ200/0AM 家族基本拓扑如下；自学手册 513 将 MQB 版本标为 DQ200-7F `0CW`，并说明 0AM 到 0CW 伴随安装位置和机电单元总线通信变化。

```text
曲轴 -> 双质量飞轮 -> 双干式离合器总成
                         ├─ K1 -> 输入轴 1 ─┬─ 1、3 挡 -> 输出轴 1 ─┐
                         │                 └─ 5、7 挡 -> 输出轴 2 ─┤
                         └─ K2 -> 输入轴 2 ─┬─ 2、4 挡 -> 输出轴 1 ─┤
                                           ├─ 6 挡    -> 输出轴 2 ─┤
                                           └─ R 中间轮 -> 输出轴 3 ─┤
                                                   三根输出轴 ─────┘
                                                            v
                                                   主减速齿轮/差速器
                                                            v
                                                       左、右半轴
```

必须按这个双支路动力流建模：K1 承担 1/3/5/7 挡，K2 承担 2/4/6/R；下一挡可在开离合一侧预选，换挡结果由两只离合器扭矩交接、同步器和轴系动态共同产生。禁止将 DQ200 简化成无换挡瞬态的单一齿比开关。

机电单元至少要保存泵状态、蓄压器压力、阀命令、离合器/选挡行程、传感器状态、适应值和热/故障状态。自学手册 390 对早期 0AM 还描述了独立的机械齿轮油与机电液压油回路；这些结构可用来定义组件接口，但油量、压力阈值和 0CW.C 零件参数必须由当前变体资料或测量重新确认。

## 7. 所需测量数据

### 7.1 身份与静态拆检

- 记录供体 VIN、PR 码、发动机/变速器/ECU/TCU/催化器/GPF 零件号及软件版本；
- 实测逐挡输入输出转数比、倒挡、各输出轴至差速器比、差速器与半轴结构；
- 三维测量气道、排气道、管路与容积，并称量/摆测关键转动件惯量；
- 记录传感器、执行器、真空/蒸发、冷却、润滑、低压电气和排气部件的真实连接图。

### 7.2 发动机台架

- 在稳定转速/负荷网格采集轴端扭矩、空气/燃油流量、轨压、节气门、增压压力、涡轮前后压力/温度、lambda、点火与喷油；
- 采集拖动摩擦图、泵气回路和附件分项功率；
- 以曲轴角同步采集各缸压力、进排气压力、喷油/点火和曲轴瞬时转速，覆盖冷机、暖机、稳态和瞬态；
- 获取压气机/涡轮或整机辨识所需的流量—压比—效率—转速数据，以及增压执行器命令/位置；
- 采集冷却液/机油流量、压力、温度和热拒绝，用于冷起动、热平衡与停机热浸。

### 7.3 排放与排气

- 同步测量发动机出口、催化器/过滤器前后和尾管的压力、温度、质量流与 lambda；
- 测量 engine-out 与 tailpipe 的 CO、CO2、HC、NOx、O2、颗粒质量/数量等适用组分，保留仪器延迟与采样管动态；
- 进行冷起动、富/稀切换、失火、减速断油、热浸再起动和受控过滤器再生试验；
- 获取后处理 light-off、储氧、转化效率、压降/积灰和热容/散热辨识数据。

### 7.4 DQ200 与集成台架

- 同步采集发动机、两根输入轴、输出/轮速、K1/K2 行程或估计扭矩、选挡位置、液压压力、泵电流和机电单元温度；
- 覆盖起步、爬行、升降挡、跳挡、制动降挡、坡起、低温/高温、反复换向、热保护和故障降级；
- 在可控滑差与温度下辨识两只离合器的传扭、摩擦、热和磨损模型，并单独辨识 DMF 扭振；
- 记录 ECU/TCU/ABS/网关时间同步总线数据，特别是驾驶员需求、允许/实际发动机扭矩、换挡阶段和扭矩干预；
- 以半轴扭矩计和高分辨率转速验证传动效率、换挡扭矩孔/峰、扭振、间隙和左右差速输出。

所有原始数据都需保存设备、校准证书、采样率、滤波、时间基准、环境和不确定度；经处理曲线必须可回溯到原始通道，不能只保留截图。

## 8. 验证与发布门槛

资产按以下顺序晋级：

1. **身份冻结**：供体与 `0CW` 后缀、排放包、软件版本全部确定；
2. **部件级**：几何/单位检查，发动机气路与热力账本、离合器/液压/轴系测试分别通过；
3. **台架级**：发动机稳态和瞬态、换挡/起步/热保护与实测数据在声明误差内；
4. **整机级**：ECU—TCU 扭矩握手、背压、12 V 功耗、冷起动后处理和半轴输出形成同一闭环；
5. **游戏级**：固定步长下确定性回放，多精度档误差有报告，宿主 FPS/音频/渲染开关不改变物理 hash；
6. **故障级**：传感器偏置/掉线、总线超时、低压、失火、增压执行器、离合器过热、液压不足和排气堵塞均有可复现的物理后果与诊断。

在这些门槛完成前，样例名称后应展示 `Research / Unverified calibration`，不得宣传为 DJS 或 DQ200 的数字孪生。

## 9. 来源边界

主要证据为上汽大众 T-Cross 保养资料、上汽大众 VIN 规则、大众自学手册 390/513，以及生态环境部对 `SVW64010DT` 环保信息公开记录的交叉确认。来源链接、页码、支持事实和限制均列于 `source_manifest.toml`。
