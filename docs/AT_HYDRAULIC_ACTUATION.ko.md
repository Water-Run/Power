# 유압 변속기 구동

[English](AT_HYDRAULIC_ACTUATION.md) · [简体中文](AT_HYDRAULIC_ACTUATION.zh-CN.md) · [Français](AT_HYDRAULIC_ACTUATION.fr.md) · [Русский](AT_HYDRAULIC_ACTUATION.ru.md) · [日本語](AT_HYDRAULIC_ACTUATION.ja.md) · **한국어** · [Deutsch](AT_HYDRAULIC_ACTUATION.de.md) · [Español](AT_HYDRAULIC_ACTUATION.es.md) · [Italiano](AT_HYDRAULIC_ACTUATION.it.md) · [Português](AT_HYDRAULIC_ACTUATION.pt-BR.md)

Ravigneaux 연구 그래프는 이제 다섯 레인지 클러치/브레이크 전부와, 점화 컨버터 실험에서는 록업에 실제 유압 피스톤을 쓸 수 있습니다. 공유되는 축 구동 펌프가 컴플라이언트 라인 압력을 공급합니다. 명시적 충전/배출 밸브가 각 액추에이터 챔버로 오일을 옮깁니다. 압력이 유한 질량 피스톤을 패드 간극 너머로 움직입니다. 탄성 접촉이 클러치 용량을 정합니다. 리턴 스프링과 감쇠가 벤트 뒤 패드를 해제합니다. 밸브 명령만으로 잠금이 성립하지는 않습니다.

## 조립 계약

`HydraulicActuationAssembly`는 명시적 SI 공급 및 액추에이터 물성을 받습니다. 기존의 펌프, 압력, 피스톤, 스프링, 밸브, 접촉 클러치 물리를 써서 불변인 보통 정의를 반환합니다. 호출자가 펌프 축, 공통 열 싱크, 선언된 대상 클러치 1..6개를 공급합니다. 각 분기는 서로 다른 챔버/슬라이더/피스톤/스프링/밸브 ID와 입력 채널 두 개가 필요합니다.

어셈블리는 대상의 예정된 마찰 체결을 `piston_clutch`로 바꿉니다. 이전 체결 입력은 없습니다. `ValveInputs`는 적용 분율을 충전 명령과 상보적인 배출 명령으로 대응시킵니다. 두 밸브는 명시적으로도 조작할 수 있습니다. 이것은 유압 경로 도우미이지, AT 제어기가 아닙니다. 용량과 잠금을 세우는 것은 물리적 압력, 이동, 패드 접촉뿐입니다.

펌프 배제 용적, 누출, 축 항력은 명시적입니다. 릴리프는 오일을 선언된 탱크 경계로 보냅니다. 어떤 압력원도 펌프 일을 대신하지 않습니다. 컴플라이언스는 `C p^2/2`를 저장합니다. 움직이는 피스톤은 압력 일을 스프링, 운동, 접촉 에너지와 교환합니다. 전/후 면적과 탱크 압력은 명시적입니다. 면적이 다르면 순 유체 재고에 해당하는 배제 체적 항이 포함됩니다. 교축, 릴리프, 리턴 감쇠, 축 항력, 클러치 슬립은 실제 손실을 공통 열 싱크로 보냅니다. 배압 일은 기존의 명시적 저장소 경계를 씁니다.

행정 스톱은 위치 클램프가 아니라 탄성 에너지 저장입니다. 게이지 압력은 기존 유압 모델로 제약됩니다. 음압은 조용한 캐비테이션 클램프가 아니라 수치적/물리적 실패입니다. 씰 누출/마찰, 유체 공기 혼입, 캐비테이션, 측정된 온도 의존 물성에는 추가 모델과 데이터가 필요합니다.

## 공유 실험

`hydraulic-ravigneaux-transmission`은 전진 상/하단 인계 동안 실제 충전과 복귀 운동으로 다섯 레인지 요소를 적용합니다. `fired-hydraulic-ravigneaux`는 엔진, 컨버터, 여섯 번째 유압 록업 액추에이터를 더합니다. 둘 다 절대 유성 자전과 궤도 관성을 유지하며, 형상과 저작 물성은 소스 설명에 기록되어 있습니다.

연구용 공급은 배제 용적 1e-6 m3/rad, 누출 1e-12 m3/(s Pa), 항력 0.02 Nm s/rad, 라인 컴플라이언스 2e-11 m3/Pa, 초기 라인 압력 1 MPa를 씁니다. 릴리프는 1 MPa에서 열리고 컨덕턴스는 5e-10 m3/(s Pa)입니다. 탱크 게이지 압력은 0입니다. 각 분기는 컴플라이언스 2e-12 m3/Pa, 전/후 면적 0.001/0 m2, 피스톤 질량 0.02 kg, 0..6-mm 행정, 2 mm에서의 패드 접촉을 갖습니다. 리턴 강성은 10000 N/m, 감쇠는 300 N s/m, 패드/스톱 강성은 1e6 N/m입니다. 이 물성은 `unverified` 연구 입력으로 남습니다.

다섯 레인지 분기는 밸브 쌍 700/701부터 708/709까지를 씁니다. 점화 록업은 710/711을 씁니다. 채널은 라인/챔버 압력, 피스톤 이동/속도, 접촉력, 용량, 실제 클러치 모드, 펌프 일, 유체 체적, 열을 노출합니다. 완전한 기계, 압력, 가스, 열 상태가 같은 해시, 분기, 취소, 배치 롤백에 참여합니다.

그래프는 이식 가능한 자산 v24와 기존 컴포넌트 레코드를 씁니다. JSON, CLI, MCP, 준비된 Studio 가져오기/재생 사례가 이 정의를 공유합니다. 독립적인 펌프-압력-운동 ODE 세밀화, 배제 체적/에너지 장부, 실제 6분기 충전, 실제 경로 확인, 모든 이식 가능 경계에는 별도 검사가 있습니다. `dotnet run --file tools/Build.cs -- verify`를 실행하세요. 수치 범위와 기록된 결과는 [VALIDATION.ko.md](VALIDATION.ko.md)에 속합니다.

## 남은 수용

스케줄은 예정된 상태로 남습니다. 센서로 확인하는 AT 순서, 폐루프 압력 제어, ECU 토크 협조, 밸브/솔레노이드 동역학, 포괄적 결함은 아직 끝나지 않았습니다. 이 일반 경로가 PSA AT8/AL4 밸브 바디의 정체성이나 OEM 교정을 세우지는 않습니다. 실제 Unity 편집기/Play/Player/IL2CPP 증거도 관리형/Standard 검사와 별개입니다. 전체 파워트레인 목표와 샘플 증거 경계는 그대로 남아 있습니다.
