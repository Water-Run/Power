## 已实现的内容

| 类型 | 职责 |
|---|---|
| `IdealGas` | 单一固定组分的量热完全气体:`R`、`gamma`、`cv`、`cp`、临界压力比,以及两个预先计算的喷管质量通量系数。 |
| `GasVolumeState` | 以**质量和内能作为独立状态**追踪的有限容积,并导出密度、温度、压力与比焓。 |
| `Orifice` | 通过节流的理想可压缩流动,带有流量系数和 `[0,1]` 内的无量纲开度分数,双向带符号,含临界与亚临界。 |

`GasVolumeState` 有意取代封闭气缸的角度加初始熵推导。因为质量与内能被独立携带,同一状态可以吸收被输运的质量、被输运的焓与壁面热,而无须假定等熵历史。

## 方程

静压使用 `p = (gamma - 1) U / V`,这对量热完全气体是精确的,并避免单独绕行温度。温度为 `T = U / (m cv)`。

质量流遵循标准的等熵喷管关系。设 `A` 为有效面积(几何面积 × 流量系数 × 开度),上游静状态为 `p_u, T_u`,压力比 `pr = p_d / p_u`:

- 临界,`pr <= (2/(gamma+1))^(gamma/(gamma-1))`:
  `mdot = A (p_u / sqrt(T_u)) sqrt(gamma/R) (2/(gamma+1))^((gamma+1)/(2(gamma-1)))`
- 亚临界:`mdot = A (p_u / sqrt(T_u)) sqrt(2 gamma / (R (gamma-1)) (pr^(2/gamma) - pr^((gamma+1)/gamma)))`

气流携带上游焓,`hdot = mdot cp T_u`,因此流动方向决定输运哪一端的温度。储气库以普通的 `(p, T)` 对传入,固定边界不需要虚拟容积。

两个分支的参考:[NASA 质量流临界](https://www.grc.nasa.gov/www/k-12/BGP/mflchk.html)。它是这些关系的参考,不是对本实现的验证。

## 数值说明

亚临界流动函数按 `pr^(2/gamma) * (1 - pr^((gamma-1)/gamma))` 求值,第二项通过 `expm1` 计算。教科书里两个几乎相等的幂之差,在 `pr` 接近 1 时会发生灾难性相消:在 `pr = 1 - 1e-12` 时大约只保留四位有效数字,而 `expm1` 形式精确到所存储比值的精度。`Numeric.Expm1` 与 `Numeric.Log1p` 现在与封闭气缸物理共享,不再各写一份。

两个极限来自模型本身而非实现,采用它的求解器必须同时处理:

- 亚临界分支在压力比为 1 处具有**无穷导数**。牛顿步不得直接穿过该点;应将其括住或加以阻尼。
- 接近 1 的比值无法在 binary64 中有用地表示。在 `pr = 1 - 1e-15` 时,偏移量大约只剩一位有效数字,无论函数如何书写。

上游滞止状态与静状态视为相等。这是通常的准稳态控制容积近似,对高马赫数气室流动**并不**成立。

## 证据

`tests/Power.Tests/GasChecks.cs` 增加六项检查,每一项都对照独立的封闭形式书写,而不是对照这段代码已记录的输出:

1. **物性与临界连续性** — 对 `gamma` 取 `{1.1, 1.3, 1.4, 5/3}`,把 `cv`、`cp` 与临界比对照其定义;亚临界分支在临界比处精确达到临界系数;流动函数单调衰减到零,在朴素形式可信处对照该形式检查,在不可信处对照主导阶展开检查。
2. **喷管流动** — 上游压力、上游温度与压力比的 54 种组合,对照完整写出的 NASA 关系,包括临界流与下游压力无关,以及焓以上游温度被携带。
3. **契约** — 交换端点时精确反对称,关闭的孔口与压力相等时流量为零,对开度分数线性,并拒绝非有限或非正的状态、`[0,1]` 之外的开度,以及无效的气体或孔口参数。
4. **绝热容器泄放** — 对 2 L 容器从 20 bar、900 K 作 RK4 积分,对照解析等熵解 `rho(t) = (rho0^-k + k C t / V)^(-1/k)`,`k = (gamma-1)/2`,密度与温度相对误差匹配到 1e-9,压力匹配到 1e-8,并带有细化检查。
5. **储气库充气** — 从 6 bar、320 K 的储气库向 0.5 L 容器充气:流动单向时精确恒等式 `dU = cp T_supply dm`,以及抽空容器极限 `T -> gamma T_supply`,从两个不同的起始压力检查。
6. **封闭双容积网络** — 热的 1.5 L 容积与冷的 0.4 L 容积之间交换 2 s:总质量相对守恒到 1e-14,总内能相对守恒到 1e-12,压力趋于相等,并确认平衡是力学平衡,而不是完全混合温度。
