# 有限气体燃油轨与循环剂量计量

[English](FUEL_METERING.md) · **简体中文** · [Français](FUEL_METERING.fr.md) · [Русский](FUEL_METERING.ru.md) · [日本語](FUEL_METERING.ja.md) · [한국어](FUEL_METERING.ko.md) · [Deutsch](FUEL_METERING.de.md) · [Español](FUEL_METERING.es.md) · [Italiano](FUEL_METERING.it.md) · [Português](FUEL_METERING.pt-BR.md)

`gas_fuel_injector` 把燃油从有限的、被追踪的气体燃油轨送入相容的气室。正向曲轴窗口每个循环锁存一份请求的燃油质量;压力、温度、喷嘴面积与可用的轨内存量决定实际供给。控制器在接近配额时节流该端口。它不会把燃油直接加进接收状态,也不会假定请求的剂量已经供给。

这扩展了当前的常物性气体混合物模型。现在可以分别建模进气、燃油计量、混合与预设反应。它不实现液态汽油喷雾、蒸发、针阀/电气动力学、液轨/油箱物理、精细组分物性,或已标定的 OEM 喷射/ECU 行为。这些仍是通向完整发动机目标所必需的工作。

## 流动、组分与能量

源与接收端是不同的有限预混气体节点。二者共享 R、gamma、热值与化学计量比。源可以是纯气体燃油,或被追踪的含燃油混合物。流动遵循既有的、依赖压力的临界/亚临界[气体孔口](GAS_NETWORK.zh-CN.md)定律,并带有显式面积与流量系数。反向压力流动是关闭的:接收端气体不会回填油轨。

配额针对的是**燃油质量**,不是源混合物的总质量。每次气体推进把燃油速率限制为 `remaining_cycle_fuel / advance_duration`。同一流动因子缩放总质量与上游热焓;组分分数使用实际的上游状态。Heun 各阶段与已接受的供给历史使用相同的转移。因此,即使轨压下降或源组分变化,接收的燃油、油轨消耗、热能与化学存量仍然一致。

内部燃油转移不进入外部的 `fuel_energy_in` 或储气库焓。源中储存的化学能随燃油移动,只有当单独的燃烧部件消耗它时才变为气体热。不兼容的化学或量热气体参数在编译时被拒绝。剂量限制改变所接纳的流动,而不是在积分之后修正质量或能量。

## 循环与指令契约

| 数据 | 含义 |
|---|---|
| 源 A / 接收端 B | 不同的有限、被追踪气体容积 |
| `area`、`discharge_coefficient` | 正的 m2/mm2,以及 (0,1] 内的系数 |
| `crank_node` | 显式的转动定时参考;运动曲轴气室使用它自己的曲轴 |
| `cycle_angle` | 360 或 720 度,带显式角度单位 |
| `start_angle`、`duration_angle` | 窗口起点,以及不大于一个循环的正持续角 |
| `maximum_dose` | 正的每循环燃油上限,单位 kg |
| 输入 `fuel_dose_per_cycle` | 请求的 kg,位于 [0,maximum_dose] |

理想矩形窗口只在正向运动期间打开。第一个被接受的开窗推进采样所请求的剂量。在该已观测循环期间的写入作用于下一个窗口;请求循环通道继续显示锁存的目标。零会禁用该循环。若可用压力或燃油不足,实际供给仍低于目标。成功的一步并不表示给足了剂量。

循环序号是由可表示的曲轴角重建的有符号有界整数。回到更早的已观测循环不能重置其配额;反向运动会关闭窗口。每个机械区间的转角限制为 `min(0.25 rad,duration/8)`。窗口端点使用既有的固定节拍/对称分裂近似,因此不连续点附近的定时需要细化时间步。并不声称存在精确的连续切换时刻。

输出包括当前计量窗口开度、上一节拍的平均供给燃油速率、锁存的请求剂量、已观测循环内的供给剂量,以及累积供给燃油。有限油轨的压力、温度与剩余燃油是普通气体通道。全部配额/序号/供给历史,包括补偿,都与推测状态一起复制和哈希。取消、后期失败与分支保留完整状态。

资产 v17 同时保留喷嘴记录与定时记录。JSON、CLI 与 MCP 共享同一模型;schema 与编译器检查单位、界限、有限且相容的端点,以及定时归属。Core 目标仍是无依赖的 net10.0/netstandard2.1。

## 实验与证据

`metered-fired-cylinder` 用仅空气的入口和有限气体燃油轨取代预混燃油进气。理想喷油器在预设 Wiebe 燃烧之前,通过曲轴窗口供给显式的 8/12/4 mg 请求。剂量变化在下一个已观测窗口被采样。十分之六秒的实验供给 28 mg,燃烧约 27.930 mg,并释放约 1228.918 J;未燃以及在边界损失的燃油仍留在组分账目中。全部参数都是合成的,且未经核实。

检查覆盖精确的配额限制供给、有限油轨存量耗尽、反向压力、窗口中途的指令锁存、反转且不重新发放配额、带光滑细化的独立双容器质量/焓 ODE、解析计量燃烧、完整事务、状态容量/单位/化学,以及无分配步进。报告、可移植资产与 MCP 在每个边界上一致。分开的供给通道与燃烧通道把已接受的指令同实际燃油与热量区分开。测得的界限与运行时/性能证据见 [VALIDATION.md](VALIDATION.zh-CN.md)。Studio 视图与 Edit/Play 测试已用 C# 9 源码准备;真实的 Unity Editor 与 Player 验收仍待完成。
