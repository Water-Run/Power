# 有界针阀闭合预测与节拍网格截止

[English](CLOSURE_PREDICTION.md) · **简体中文** · [Français](CLOSURE_PREDICTION.fr.md) · [Русский](CLOSURE_PREDICTION.ru.md) · [日本語](CLOSURE_PREDICTION.ja.md) · [한국어](CLOSURE_PREDICTION.ko.md) · [Deutsch](CLOSURE_PREDICTION.de.md) · [Español](CLOSURE_PREDICTION.es.md) · [Italiano](CLOSURE_PREDICTION.it.md) · [Português](CLOSURE_PREDICTION.pt-BR.md)

[物理针阀驱动器](NEEDLE_ACTUATION.zh-CN.md)可以补偿电压指令结束后仍供给的燃油。可选的 `closure_prediction_ns` 启用单独的、预分配的全装置回放。真实的针阀升程、电流衰减、压力功、阀座回弹与燃油存量仍然是物理的;预测改变的是指令定时,而不是裁剪实际供给质量。

## 预测契约

在到期采样时,预测器复制完整的当前状态。它以线圈零电压,或在截止前有一段有界的驱动电压,回放所配置的物理节拍。所有其他执行器指令保持不变。采样控制器不会在该预测内部递归或改变指令,也不会预先计入将来的外部输入事件。换气、曲轴/气缸行为、燃烧、液压/电气供给、接触以及已接受的离合器区间,继续按正常的装置方程进行。

预测的附加质量是该喷油器总供给的增量。暂存状态从不提交到真实仿真。每个候选都从同一完整源状态开始;真实时间、控制器记忆与物理历史保持不动。仿真所拥有的求解器工作区会为真实区间重新准备。`PredictNeedleClosure(driver_id, out estimate)` 为 Core 客户端暴露只读的零电压预测,并带有取消与状态。

预测时域是物理节拍的整数倍,至少覆盖两个驱动器采样周期,并且限制为 **4096 个物理节拍**。零保留先前的通断驱动器行为。预测不能回绕有界整数时钟。失败或取消的预测会拒绝整个真实批次;部分预测不会被悄然当作有效估计。

## 计划中的关闭决定

驱动器把当前循环供给加上预测的闭合燃油,与锁存请求相比较。若零电压闭合已经达到目标,它立即切断。否则,它还预测保持驱动直到下一次采样。若这两个候选夹住目标,有界整数二分找出相邻的物理节拍截止候选,并选择投影最终质量更接近的一个。

所选截止时刻是物理节拍的倒计时。它可以在下一次控制器采样之前撤去电压。截止决定为已观测循环锁存,以避免在微小预测差异上反复重新开启。新的已观测循环会重置该锁存。窗口关闭或反转停机可以取消尚未到期的截止。在整个关闭与回弹期间,实际燃油仍由运动中的针阀决定。

局部候选区间必须在所声明的数值容差内单调。违反的区间返回数值失败,模型/会话状态不变;应检查电压、机械、采样与预测假设,而不是接受无效截止。每个候选限制为 4096 个节拍,整数二分最多有十二次内部查询,外加端点预测。

这是基于模型的通断定时,不是预测燃烧、标定的 ECU 控制、稳健的故障管理或实测喷油器图谱。保持其他指令并略去将来的外部事件,是显式的预测假设。将来负载、压力或控制器动作的变化可以改变实际供给。

## 时域与物理精度

有限预测必须包含相关的关闭/回弹燃油。在孤立的研究执行器中,8 ms 预测会截断不可忽略的后期尾段;20/30 ms 预测给出相同的节拍网格决定。时域研究作为证据保留,而不是把任意的短预测当作完整闭合。

物理时间步、控制器采样周期与预测时域是各自独立的精度控制。更长的时域并不能修补粗糙的电气/接触积分,也不能修补并不准确的本构模型。在同一保持输入模型下预测与实际相等,验证的是实现,不是 OEM 标定。底层装置中的解析检查、独立 ODE 检查、守恒检查与事件检查仍然适用。

## 可观测量与事务

启用预测的驱动器输出包括:

- `predicted_fuel_mass`:所选闭合候选的附加燃油,kg。
- `prediction_ticks`:所配置的物理回放次数。
- `driver_state`:是否已为已观测循环锁存截止。
- `closing_delay_ticks`:距离计划撤去电压还剩的物理节拍数。

所保持的电压与上一采样的目标/供给仍然可用。预测量包含任何计划中的驱动延迟,而公开的 Core 只读查询始终预测立即的零电压闭合。这些量不是实际燃油转移,也不进入质量、化学或能量账本。

启用预测时,每个驱动器另外五个被报告的状态项保留预测质量/计数、截止锁存/循环以及倒计时。单独的回放状态每个仿真分配一次。预热之后,读取、成功的活动步进与快照不分配托管内存。取消、修订、独立分支、推测离合器捕获以及后期数值失败,保留全部预测/控制历史与物理历史。禁用预测时保留先前的指纹与哈希。

## 共享定义与证据

JSON 接受可选的 `needle_driver.parameters.closure_prediction_ns`。Core 使用 `NeedleDriverDefinition.ClosurePredictionNanoseconds`。能力声明界限、保持假设与可观测量;`closure-compensated-cylinder` 是共享示例。源的 `kg` 请求仍可写,线圈电压仍归驱动器所有。成功的请求不同于实际的剂量跟踪,也不同于通过的 KPI。

资产 v21 保留既有计数表,并用一个时域 uint64 把每条驱动器记录从 32 字节扩展到 40 字节。先前的读取器默认禁用预测;一份真实的 v20 夹具保留其指纹与同一运行时回放。启用预测会加入指纹标签 25 以及所配置的时域。有界计数、单位、时域/对齐、控制器归属与降级拒绝都会检查。

孤立的 8 mg 请求、完整点火实验室、时域研究、不可变模型、只读预测与独立手动闭合、完整回放、零分配以及已取消或失败的批次,都在 [VALIDATION.md](VALIDATION.zh-CN.md) 中得到验证。完整的发动机/变速器/控制、实测物理/驱动图谱、油轨回充、真实 Unity 以及标定车辆验收仍未完成。
