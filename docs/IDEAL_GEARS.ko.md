# 이상 기어와 유성 기준

[English](IDEAL_GEARS.md) · [简体中文](IDEAL_GEARS.zh-CN.md) · [Français](IDEAL_GEARS.fr.md) · [Русский](IDEAL_GEARS.ru.md) · [日本語](IDEAL_GEARS.ja.md) · **한국어** · [Deutsch](IDEAL_GEARS.de.md) · [Español](IDEAL_GEARS.es.md) · [Italiano](IDEAL_GEARS.it.md) · [Português](IDEAL_GEARS.pt-BR.md)

`Power.Core`는 불변이고 할당이 없는 두 일정 부하 기준 `IdealGearPair`와 `SimplePlanetaryGear`를 제공합니다. 이들은 부재 속도, 각 진행, 반력 토크, 외부 일, 운동 에너지 변화, 에너지 잔차를 반환합니다. 결합 변속기 솔버에 대한 독립적인 해석 증거입니다. 별도의 [결합 기어 솔버](GEAR_NETWORK.ko.md)는 이제 JSON, 이식 가능한 자산, CLI/MCP를 통해 영구 기어와 유성 컴포넌트를 노출하며, 클러치로 제어하는 변속 실험도 포함합니다. 기준 클래스는 순수한 국소 해석 해로 남습니다.

## 물리 범위와 부호

이상 기어에는 물림 관성, 컴플라이언스, 백래시, 손실이 없습니다. 공급된 관성은 모두 부착된 로터 관성입니다. 쌍의 두 관성, 또는 유성의 세 부재는 모두 양수이고 유한해야 합니다. 접지와 질량 없는 노드는 관성 0에서 추론하지 않습니다. 이 추상화는 Modelica Standard Library의 [IdealGear](https://doc.modelica.org/Modelica%204.0.0/Resources/helpWSM/Modelica/Modelica.Mechanics.Rotational.Components.IdealGear.html)와 [IdealPlanetary](https://doc.modelica.org/Modelica%204.0.0/Resources/helpWSM/Modelica/Modelica.Mechanics.Rotational.Components.IdealPlanetary.html)의 범위를 따릅니다. Power!의 구현은 독립적으로 작성되었습니다. 제3자 구현은 포함되거나 호출되지 않습니다.

쌍에서 부호 있는 비 `r`은 다음을 정의합니다.

```text
omega_A = r omega_B
reaction_A = lambda
reaction_B = -r lambda
```

양의 비는 포트 방향이 같고, 음의 비는 방향을 뒤집습니다. 반력은 **부착된 로터에 작용하는** 토크이지, 로터가 기어에 가하는 토크가 아닙니다. 호환되는 운동에 대해 순 일은 0입니다. 기어 쌍의 하우징은 반력을 받을 수 있습니다. 두 로터의 보통 각운동량만으로는 일반적으로 보존되지 않습니다. 일반화 운동량 `r J_A omega_A + J_B omega_B`는 일반화 외부 토크 `r T_A + T_B`에 따라 변합니다.

단순 유성에서 선, 링, 캐리어는 하나의 양의 축을 공유합니다. 잇수 비 `k = N_ring / N_sun`은 1보다 커야 합니다. 기구 관계와 두 개의 독립 자유도는 [MathWorks 유성 기어 방정식](https://www.mathworks.com/help/sdl/ref/planetarygear.html)과 일치합니다.

```text
omega_S + k omega_R = (1+k) omega_C
reaction_S = lambda
reaction_R = k lambda
reaction_C = -(1+k) lambda
```

이 반력의 합은 0이고 순 일도 0입니다. 모델은 연속 비를 받아들이며, 잇수, 모듈, 이 강도, 제작 가능한 형상을 추론하지 않습니다. 유성 자전/궤도 관성, 손실, 베어링, 윤활, 열 거동은 이 기준 밖에 있습니다.

## 독립적인 축소 좌표 해

쌍의 운동은 포트 B를 독립 좌표로 씁니다.

```text
J_equivalent_B = r^2 J_A + J_B
alpha_B = (r T_A + T_B) / J_equivalent_B
alpha_A = r alpha_B
```

유성은 운동 에너지 질량 행렬을 만들기 전에 캐리어 운동을 소거합니다. `a = 1/(1+k)`, `b = k/(1+k)`일 때:

```text
omega_C = a omega_S + b omega_R

M = [ J_S + a^2 J_C,    ab J_C        ]
    [ ab J_C,           J_R + b^2 J_C ]

M [alpha_S, alpha_R]^T = [T_S + a T_C, T_R + b T_C]^T
alpha_C = a alpha_S + b alpha_R
```

구현은 이 2×2 행렬을 스케일하고, 거의 같은 곱의 뺄셈을 피하도록 행렬식을 양의 항으로 전개합니다. 일정 부하에서 가속도는 일정하므로, 속도와 변위는 부동소수점 반올림까지 정확한 선형/이차 시간 적분을 따릅니다. 그다음 부재 방정식에서 반력 토크를 복원합니다. 검사는 자유 유성에 대해 독립적인 가속도 제약 승수를 씁니다. 기대 해로 축소 행렬을 재사용하지 않습니다.

## 상태, 단위, 실패 계약

공개 속성 이름은 SI 단위를 가집니다. kg m2, rad/s, rad, N m, J, 초입니다. 비는 무차원입니다. `Advance`는 양의 유한한 국소 지속 시간을 받고 `GearStepStatus`를 반환합니다. 이 국소 기준 지속 시간은 `Simulation`의 유계 정수 시계를 대체하지 않습니다. 클래스는 진화하는 상태를 갖지 않습니다. 입력은 값 레코드입니다. 거부가 있으면 출력은 기본값이고, 독립된 호출자가 인스턴스를 공유할 수 있습니다.

초기 속도는 이미 관계를 만족해야 합니다. 호환성은 binary64 엡실론 `2.2204460492503131e-16`의 상대 반올림 검사를 쓰며, 절대 저속 데드밴드는 없습니다. 쌍의 한계는 `64 epsilon (|omega_A| + |r omega_B|)`입니다. 유성은 캐리어 속도를 만든 연산에 대해 소거를 상대적으로 다루도록, 두 가중 속도 항의 크기도 포함합니다. 허용 오차가 넘치지 않도록 항을 더하기 전에 스케일합니다.

검증 뒤, 종속 속도와 각 진행은 독립 좌표에서 재구성됩니다. 이것은 수용된 반올림 잔여를 제거하는 것이지, 유한 슬립의 체결이나 동기화 계산이 아닙니다. 호환되지 않는 속도는 `IncompatibleState`를 반환합니다. 실제 속도 불일치에는 그 에너지를 버리는 대신 명시적 클러치/충격 모델을 쓰세요. 절대 기어 위상은 지정되지 않습니다. 보고되는 것은 각 진행뿐입니다.

잘못된 생성 매개변수는 조치할 수 있는 인자 예외를 던집니다. 비유한하거나 조건이 나쁜 매개변수 조합은 거부됩니다. 스케일된 유성 행렬식은 `64 epsilon`을 넘어야 합니다. 구간 거부는 잘못된 지속 시간, 잘못된 상태, 호환되지 않는 상태, 잘못된 토크, 수치 실패를 구분합니다. 산술 오버플로는 `NumericalFailure`를 반환합니다. 유한한 입력만으로 유도량이 표현 가능하다는 보장은 없습니다. 실행 중 힘 평형 검사는, 유한하지만 일관되지 않은 부재 반력을 남기는 소거도 거부합니다. 각 힘 잔차는 관성, 적용, 반력 토크 크기의 합에 `512 epsilon`을 곱한 값으로 제한됩니다. 수용된 끝점은 각 부재의 임펄스 평형도 검사합니다. 이전/새 운동량과 적용/반력 임펄스의 크기에 `512 epsilon`을 곱한 값을 씁니다. 후자는 종속 속도 재구성에서 과도한 소거를 감지합니다. 이 검사는 잔차를 제한하는 것이지, 임의로 조건이 나쁜 매개변수의 해 오차를 제한하는 것이 아닙니다. 검사에는 유한한 소거 실패와, 작은 반력이 관측 가능해야 하는 높은 비의 쌍이 포함됩니다. 잔차는 `external_work - kinetic_energy_change`입니다. 마찰열은 만들어 내지 않습니다.

## 변속 상태와 증거

검사는 이 이상적 한계를 세우기 위해 고정 또는 잠금 토크를 명시적으로 공급합니다.

| 부과된 조건 | 결과 속도 관계 |
|---|---|
| 링 고정 | `omega_C = omega_S / (1+k)` |
| 선 고정 | `omega_C = k omega_R / (1+k)` |
| 캐리어 고정 | `omega_S = -k omega_R` |
| 선이 링에 잠김 | 세 부재의 속도가 모두 같음 |

공급된 브레이크는 그 부재가 고정되어 있으면 일이 0입니다. 선/링 잠금은 서로 반대 토크를 받고 합산 일은 0입니다. 이 검사는 정적 변속 상태를 세웁니다. 이 기준은 변속, 클러치 체결, 유압 회로, TCU를 구현하지 않으며, 임의의 외부 토크가 부재를 자동으로 고정하지도 않습니다.

같은 여덟 개 검사 그룹이 `net10.0`과 `netstandard2.1`에 대해 실행됩니다.

- 부호 있는 비와 반사 관성. 반력 동력과 부재별 임펄스 평형.
- 독립적인 힘 승수 해에 대한 자유 유성 운동.
- 부재를 고정한 세 경우와 직결. 명시적 고정/잠금 부하를 사용합니다.
- 일정 부하의 분할 불변성과 0을 지나는 속도 반전.
- 두 기준 모두에 대해, 독립 적분과 비교한 사인 부하. 구간을 반으로 줄이면 속도/각 오차가 약 4배로 줄어듭니다.
- 잘못된 관성/비/상태/부하 값, 호환되지 않는 속도, 나쁜 조건, 오버플로.
- 각 기준에 대한 2,500개의 결정적 사례. 일, 운동량, 재현성을 검사합니다.
- 각 원시 요소를 10,000번 반복 평가했을 때 관리형 할당이 0이고, 독립된 동시 호출자가 불변 인스턴스를 공유합니다.

전체 직렬 검증 결과는 [검증 기록](VALIDATION.ko.md)을 참고하세요. Standard 어셈블리 검사는 .NET 10에서 실행되며 Unity 편집기/Play/IL2CPP 증거는 제공하지 않습니다.

## 결합 적분

영구 제약은 이제 전기기계/실린더/클러치 풀이에 참여합니다. 독립된 시뮬레이션 작업 공간, 완전한 롤백, 안정된 반력/오차 채널을 갖습니다. JSON/스키마, 이전 판독기가 있는 자산 v8, MCP 탐색과 리플레이는 같은 토폴로지를 씁니다. 점화 유성 실험은 감속/직결 상단 변속과 하단 변속을 수행합니다. 방정식과 증거는 [결합 계약](GEAR_NETWORK.ko.md)을 참고하세요. 완전한 DCT/AT 토폴로지, 컨버터, 유압, 제어, 완전한 엔진 거동, 측정된 차량 교정은 전체 Power! 목표의 일부로 남아 있습니다.
