# 유계 니들 폐쇄 예측과 틱 격자 차단

[English](CLOSURE_PREDICTION.md) · [简体中文](CLOSURE_PREDICTION.zh-CN.md) · [Français](CLOSURE_PREDICTION.fr.md) · [Русский](CLOSURE_PREDICTION.ru.md) · [日本語](CLOSURE_PREDICTION.ja.md) · **한국어** · [Deutsch](CLOSURE_PREDICTION.de.md) · [Español](CLOSURE_PREDICTION.es.md) · [Italiano](CLOSURE_PREDICTION.it.md) · [Português](CLOSURE_PREDICTION.pt-BR.md)

[물리적 니들 드라이버](NEEDLE_ACTUATION.ko.md)는 전압 명령이 끝난 뒤에 공급된 연료를 보상할 수 있습니다. 선택적 `closure_prediction_ns`는 미리 할당된, 별도의 전체 플랜트 리플레이를 켭니다. 실제 니들 양정, 전류 감쇠, 압력 일, 시트 반발, 연료 재고는 물리적으로 남습니다. 예측은 실제 공급 질량을 잘라 내는 대신, 명령 타이밍을 바꿉니다.

## 예측 계약

도래한 샘플에서 예측기는 완전한 현재 상태를 복사합니다. 코일 전압 0으로, 또는 차단 전에 유계된 기간의 구동 전압으로, 설정된 물리 틱을 리플레이합니다. 다른 액추에이터 명령은 모두 유지됩니다. 샘플링 제어기는 이 예측 안에서 재귀하거나 명령을 바꾸지 않으며, 미래의 외부 입력 이벤트는 예상되지 않습니다. 가스 교환, 크랭크/실린더 거동, 연소, 유압/전기 공급, 접촉, 수용된 클러치 구간은 통상적인 플랜트 방정식을 통해 계속됩니다.

예측된 추가 질량은 그 인젝터 총 공급의 증가분입니다. 스크래치 상태는 실제 시뮬레이션에 커밋되지 않습니다. 모든 후보는 같은 완전한 원본 상태에서 시작합니다. 실제 시각, 제어기 메모리, 물리 이력은 건드리지 않습니다. 시뮬레이션이 소유한 솔버 작업 공간은 실제 구간을 위해 다시 준비됩니다. `PredictNeedleClosure(driver_id, out estimate)`는 Core 클라이언트에 읽기 전용 영전압 예측을 노출하며, 취소와 상태를 동반합니다.

지평은 물리 틱의 정수 배이고, 드라이버 샘플 주기 둘 이상을 덮으며, **물리 틱 4096개**로 제한됩니다. 0은 이전의 온/오프 드라이버 거동을 유지합니다. 예측은 유계 정수 시계를 감쌀 수 없습니다. 실패하거나 취소된 예측은 실제 배치 전체를 거부합니다. 부분 예측이 조용히 유효한 추정치로 취급되지는 않습니다.

## 예정된 닫힘 결정

드라이버는 현재 사이클 공급에 예측된 닫힘 연료를 더한 값을 래치된 요청과 비교합니다. 영전압 폐쇄가 이미 목표에 닿으면 지금 끊습니다. 그렇지 않으면 다음 샘플까지 구동을 유지하는 예측도 합니다. 두 후보가 목표를 사이에 두면, 유계 정수 이분법이 이웃한 물리 틱 차단 후보를 찾고, 투영된 최종 질량이 더 가까운 쪽을 고릅니다.

선택된 마감은 물리 틱의 카운트다운입니다. 다음 제어기 샘플보다 일찍 전압을 제거할 수 있습니다. 차단 결정은 관측 사이클에 대해 래치되어, 아주 작은 예측 차이로 반복해서 다시 열리는 일을 피합니다. 새로 관측된 사이클은 그 래치를 재설정합니다. 창/역전 정지는 대기 중인 마감을 취소할 수 있습니다. 실제 연료는 닫힘과 반발 내내 움직이는 니들이 지배합니다.

국소 후보 구간은 선언된 수치 허용 오차 안에서 단조여야 합니다. 깨진 구간은 모델/세션 상태를 바꾸지 않은 채 수치 실패를 반환합니다. 잘못된 차단을 받아들이는 대신, 전압, 기계, 샘플링, 예측 가정을 검사하세요. 각 후보는 4096틱으로 제한되고, 정수 이분법은 끝점 예측에 더해 내부 질의가 최대 열두 번입니다.

이것은 모델 기반 온/오프 타이밍이지, 예측 연소, 교정된 ECU 제어, 강건한 결함 관리, 실측 인젝터 맵이 아닙니다. 다른 명령을 유지하고 미래의 외부 이벤트를 빼는 것은 명시적 예측 가정입니다. 미래의 부하, 압력, 제어기 동작이 바뀌면 실제 공급이 바뀔 수 있습니다.

## 지평과 물리적 정확성

유한 예측은 관련 있는 닫힘/반발 연료를 포함해야 합니다. 고립된 연구 액추에이터에서 8 ms 예측은 무시할 수 없는 늦은 꼬리를 잘라 냅니다. 20/30 ms 예측은 같은 틱 격자 결정을 줍니다. 지평 연구는, 임의의 짧은 예측을 완전한 폐쇄로 다루는 대신, 증거로 유지됩니다.

물리 시간 스텝, 제어기 샘플 주기, 예측 지평은 서로 다른 정확성 조절입니다. 더 긴 지평이 거친 전기/접촉 적분이나 부정확한 구성 모델을 고치지는 않습니다. 같은 유지 입력 모델에서 예측과 실제가 같음은 구현을 검증하지, OEM 교정을 검증하지는 않습니다. 기반 플랜트의 해석적 검사, 독립 ODE 검사, 보존 검사, 이벤트 검사는 여전히 적용됩니다.

## 관측량과 트랜잭션

예측이 켜진 드라이버 출력에는 다음이 포함됩니다.

- `predicted_fuel_mass`: 선택된 닫힘 후보의 추가 연료, kg.
- `prediction_ticks`: 설정된 물리 리플레이 횟수.
- `driver_state`: 관측 사이클에 대해 차단이 래치되었는지.
- `closing_delay_ticks`: 예정된 전압 제거까지 남은 물리 틱.

유지된 전압과 마지막 샘플의 목표/공급은 계속 사용할 수 있습니다. 예측량은 계획된 구동 지연을 포함합니다. 반면 공개된 Core 읽기 전용 질의는 항상 즉시 영전압 폐쇄를 예측합니다. 이 양들은 실제 연료 전달이 아니며, 질량, 화학, 에너지 장부에 들어가지 않습니다.

예측이 켜지면, 드라이버마다 추가 보고 상태 항목 다섯이 예측 질량/횟수, 차단 래치/사이클, 카운트다운을 유지합니다. 별도의 리플레이 상태는 시뮬레이션마다 한 번 할당됩니다. 읽기, 성공한 활성 스텝, 스냅샷은 워밍업 뒤에 관리 메모리를 할당하지 않습니다. 취소, 개정, 독립 분기, 투기적 클러치 포획, 늦은 수치 실패는 모든 예측/제어 이력과 물리 이력을 보존합니다. 꺼진 예측은 이전 지문과 해시를 유지합니다.

## 공유 정의와 증거

JSON은 선택적 `needle_driver.parameters.closure_prediction_ns`를 받습니다. Core는 `NeedleDriverDefinition.ClosurePredictionNanoseconds`를 씁니다. 기능은 한계, 유지 가정, 관측량을 선언합니다. `closure-compensated-cylinder`가 공유 예제입니다. 원천의 `kg` 요청은 계속 쓸 수 있고, 코일 전압은 드라이버 소유로 남습니다. 성공한 요청은 실제 도즈 추적이나 KPI 통과와 다릅니다.

자산 v21은 기존 개수 표를 유지하고, 지평 uint64로 각 드라이버 기록을 32바이트에서 40바이트로 늘립니다. 이전 판독기는 예측 끄기를 기본으로 합니다. 진본 v20 픽스처는 지문과 같은 런타임 리플레이를 유지합니다. 켜진 예측은 지문 태그 25와 설정된 지평을 더합니다. 유계 개수, 단위, 지평/정렬, 제어기 소유, 다운그레이드 거부가 검사됩니다.

고립된 8 mg 요청, 완전한 점화 실험실, 지평 연구, 불변 모델, 읽기 전용 예측/독립적인 수동 폐쇄, 완전한 리플레이, 할당 0, 취소되거나 실패한 배치가 [VALIDATION.ko.md](VALIDATION.ko.md)에서 검증됩니다. 완전한 엔진/변속기/제어, 실측 물리/구동 맵, 레일 보충, 실제 Unity, 교정된 차량 수용은 아직 끝나지 않았습니다.
