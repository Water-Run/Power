# 개발 상태

[English](DEVELOPMENT_STATUS.md) · [简体中文](DEVELOPMENT_STATUS.zh-CN.md) · [Français](DEVELOPMENT_STATUS.fr.md) · [Русский](DEVELOPMENT_STATUS.ru.md) · [日本語](DEVELOPMENT_STATUS.ja.md) · **한국어** · [Deutsch](DEVELOPMENT_STATUS.de.md) · [Español](DEVELOPMENT_STATUS.es.md) · [Italiano](DEVELOPMENT_STATUS.it.md) · [Português](DEVELOPMENT_STATUS.pt-BR.md)

Power!에는 관리형 시뮬레이션 코어, 공유 모델 문서와 이식 가능한 자산, 헤드리스 CLI, MCP 에이전트 서비스, 준비된 Unity 스튜디오가 있습니다. 합성 실험실은 엔진, 변속기, 유압, 전기 거동을 실행합니다. 완전한 파워트레인, 조율된 ECU/TCU 제어, 실측 교정, 수용된 Unity 데스크톱 응용 프로그램은 아직 끝나지 않았습니다.

코어와 Assets는 `net10.0`과 `netstandard2.1`을 모두 대상으로 합니다. 코어에는 Unity, 전송, 모델 공급자, 제3자 의존성이 없습니다. Unity Assets 스크립트는 C# 9를 사용합니다. Unity는 외부 SDK가 빌드한 Standard 어셈블리를 로드합니다. .NET 10/C# 14 소스를 컴파일하지는 않습니다.

## 증거와 한계

필수 직렬 명령 `dotnet run --file tools/Build.cs -- verify`는 두 어셈블리 대상, 실제 MCP 프로세스, 모든 실험실, Zig 보관 코드와 C# ABI를 검사합니다. 수치, 결과와 로그 경로는 [VALIDATION.md](VALIDATION.md)에 있습니다. .NET 10에서 실행한 Standard 어셈블리 검사는 Unity 런타임 인수를 입증하지 않습니다.

연료 공급에는 [유한 탱크](LIQUID_FUEL_TANK.ko.md)와 [추적 가능한 릴리프 반환](LIQUID_FUEL_RETURN.ko.md)이 포함되며 질량, 열/화학 에너지와 압력 일 수지를 보존합니다. [유압 AT 제어기](AT_CONTROL.ko.md)는 액추에이터 압력을 조절하고 실제 기어/록업을 확인합니다. 독립 참조와 전체 트랜잭션이 연구 모델을 뒷받침합니다. 전체 ECU/TCU 조정과 실측 하드웨어 동작은 아직 미완성입니다.

현재 환경에서 `POWER_UNITY_EDITOR`는 설정되지 않았습니다. Studio 가져오기, 재현과 준비된 테스트는 실제 Editor/Play, 렌더링과 Player/IL2CPP 증거가 필요합니다.

모든 매개변수는 계속 `unverified`입니다. EA211 DJS + DQ200과 PSA EC5 + AT8은 [assets/samples](../assets/samples)에 전체 경계와 증거 목록을 유지합니다. 누락된 OEM 측정값은 누락 상태로 둡니다. 라이선스와 역사적 소스 출처는 보존됩니다.

CLI `list-labs`, MCP 예제 검색과 직렬 검증은 [하나의 실험실 목록](../assets/labs/catalog.json)을 공유합니다. 검증은 모든 실험실 소스가 포함되는지 검사합니다.

## 다음 개발 순서

1. 압력 의존 상평형, 캐비테이션, 실측 펌프 충액/조압과 정밀 자기/전자 구동을 확장합니다. 유한 액체 체적과 분무 운동량이 분해되면, 선언된 내보내기 변위 일 경계를 대체합니다. 공급된 액체, 증발된 연료, 반응을 따로 관측할 수 있게 유지하고, 독립 기준을 유지합니다.
2. 점화 제어, 흡기/배기 동역학, 기계 손실, 더 풍부한 열화학으로 엔진을 확장합니다. 완전한 엔진 목표를 유지합니다.
3. DCT 구동과 실측 유성기어/AT 유압을 확장한 다음 기존 샘플 DCT 및 AT 제어기로 ECU/TCU 토크 요청과 변속을 조정합니다. 실측 센서, 액추에이터와 복구 가능한 결함을 추가합니다.
4. 고정된 편집기로 `unity-test`를 실행한 뒤 Player/IL2CPP 증거를 얻습니다. 채널 선택, 그래프 편집, 저장을 별도 기능으로 완성합니다.
5. 교정된 샘플이나 릴리스 준비를 선언하기 전에, 두 목표 파워트레인에 대한 실측 맵, OEM 데이터, 불확실성 예산을 얻습니다.
