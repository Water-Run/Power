# 有限液体油膜与蒸发

[English](FUEL_FILM.md) · **简体中文** · [Français](FUEL_FILM.fr.md) · [Русский](FUEL_FILM.ru.md) · [日本語](FUEL_FILM.ja.md) · [한국어](FUEL_FILM.ko.md) · [Deutsch](FUEL_FILM.de.md) · [Español](FUEL_FILM.es.md) · [Italiano](FUEL_FILM.it.md) · [Português](FUEL_FILM.pt-BR.md)

`fuel_film` 在被追踪的气体接收端旁储存一份显式的初始液体存量。有限热节点提供显热与相变热。蒸发的燃油加入接收端的质量、内能与燃油组分;既有的预混反应只消耗蒸气。液体存量是初始润湿,不是喷入的燃油,并且仍属于总质量与化学能账本。

这是常物性的研究模型,液体排开容积可忽略,饱和温度是预设的。它不实现液轨、针阀或喷雾动力学、依赖压力的相平衡、冷凝、多组分燃油物性或已标定的汽油行为。

## 相变能量与有限热源

设 `c_l` 为液体比热,`c_v` 为接收端气体的定容比热,`T_s` 为所声明的饱和温度,`L_u > 0` 为 `T_s` 处蒸气减液体的比内能差。共享的热参考是:

```text
e_offset = (c_v - c_l) T_s - L_u
U_liquid = m_liquid (c_l T_liquid + e_offset)
U_vapor_added = delta_m c_v T_s
```

`L_u` 是以 J/kg 计的内能差,而不是汽化焓。若要使用给定的焓,必须先做显式且有依据的换算。在这一参考下,液体热能可以为负;温度与质量仍必须在物理上可接受。化学能 `m_liquid * LHV` 是分开的,随蒸气转移,而不产生反应热或外部源功。

低于饱和时,热导 `K` 把液体热容 `m_liquid c_l` 与有限壁面热容 `C_w` 耦合起来。温差以速率 `K (1 / (m_liquid c_l) + 1 / C_w)` 解析衰减。热容加权平均温度保持不变。若液体达到 `T_s`,该定律解出该时刻,并把剩余区间用于蒸发。

饱和且 `T_wall > T_s` 时,壁面过热以速率 `K / C_w` 衰减。区间 `h` 上可用的相变热为 `C_w (T_wall - T_s) (1 - exp(-K h / C_w))`,并以 `m_liquid L_u` 为上限。油膜在蒸干之前保持在 `T_s`;蒸发质量是相变热除以 `L_u`。蒸干后液体质量与能量恰好为零,并停止吸热。冷壁可以冷却已有液体;它不会冷凝接收端的蒸气。

每次转移满足 `delta U_liquid + U_vapor_added = Q_from_wall`。壁面失去同样的热量,因此相变不引入外部能量边界。非负燃油存量与完整组分账本独立于总能量账本接受检查。

## 图与文档契约

| 数据 | 要求 |
|---|---|
| `node_a` | 有限气体接收端,带显式的预混燃油追踪与 LHV |
| `node_b` | 有限热壁,热容与温度为正 |
| `initial_mass` | 非负的 kg;完整的初始液体存量 |
| `initial_temperature` | 正的 K,且不高于饱和温度 |
| `liquid_specific_heat` | 正的 J/(kg K),JSON 单位 `j_kg_k` |
| `saturation_temperature` | 正的 K,JSON 单位 `k` |
| `latent_internal_energy` | 正的 J/kg,JSON 单位 `j_kg` |
| `conductance` | 非负的 W/K,JSON 单位 `w_k` |

JSON 要求全部六个参数。油膜没有输入通道、曲轴定时或单独的热汇。无关参数、错误的端口域、单位、非有限值以及不受支持的状态容量会被拒绝。Core 调用方使用 `ComponentDefinition.LiquidFilm` 与 `FuelFilmDefinition`;独立的 `EquilibriumFuelFilm` 定律暴露可接受状态的创建与有限热浴推进。

每片油膜向编译器的有界状态预算贡献五个被报告的状态项。质量、热能、蒸发历史、平均流、壁面热及其补偿历史归仿真所有。取消、被拒绝的输入、后期求解失败、独立分支与推测离合器区间保留完整事务。预热之后,成功的步进与快照读取不分配托管内存。

## 积分精度

被接受的区间使用油膜 / 气体 / 机械与反应 / 气体 / 油膜半步。共享壁面的油膜在气体推进之前按稳定的部件顺序运行,之后则顺序相反。它们的有限壁温在油膜子步之间传递,壁面热进入同一次热求解。

孤立的有限热浴定律在显热加热、饱和与蒸干全程是解析的。独立的联立 ODE 积分验证二阶光滑细化:两片油膜共享一面壁,以及蒸气经临界气体出口输运,且没有其他壁面热源。气体热链与其他热源仍读取显式的外层区间壁温,因此该耦合保持一阶精度。反应窗口、气门事件与蒸干需要各自的细化检查;精确的批次回放本身并不能证明时间步精度,也不能证明点火动力总成具有一致的二阶精度。

## 可观测与可移植语义

| 油膜字段 | 含义 |
|---|---|
| `mass` | 剩余液体燃油,kg |
| `temperature` | 液体温度;蒸干时为所声明的饱和温度 |
| `internal_energy` | 在所声明相变参考下的带符号液体热能,J |
| `chemical_energy` | 剩余液体燃油的化学能,J |
| `evaporated_fuel_mass` | 累积供给的蒸气,kg |
| `mass_flow` | 上一个完整物理节拍上的平均蒸气供给,kg/s |
| `film_wall_heat` | 从壁面吸取的累积热量,J;冷却时可以为负 |
| `heat_flow` | 瞬时 `K (T_wall - T_liquid)`,W;蒸干时为零 |

通过校验或创建会话来发现输出 ID 与单位。全局质量、燃油与化学能可观测量包含油膜存量。内部蒸气供给不会增加储气库燃料能量或外部焓。

资产 v19 储存全部相变物性,并保留 v1-v18 读取器。每片油膜需要一条带类型的 64 字节相变记录。有界的长度/计数、摘要、完整覆盖、重复/缺失记录、单位、物理编译与降级防护都会检查。真实的 v17 燃油计量夹具保留其指纹,以及同一运行时的升级回放。参见 [ASSET_FORMAT.md](ASSET_FORMAT.zh-CN.md)。

## 实验室与剩余工作

`film-fired-cylinder` 加热初始润湿的油膜,单独进气,再通过预设的 Wiebe 燃烧消耗可用蒸气。有限热壁支付相变热;液体不直接燃烧。JSON、CLI、可移植回放与真实的 MCP 服务器在每个报告边界上一致。源、schema 与会话契约仍然共享;参数为 `unverified`。

测得的数值证据见 [VALIDATION.md](VALIDATION.zh-CN.md)。已准备的 Unity 油膜标记与生命周期检查仍需要真实的 Editor/Play 验证。单独的[液体喷油器](LIQUID_FUEL_INJECTION.zh-CN.md)现在从有限柔性源补充油膜。泵/回充、针阀/喷雾、实测燃油物性、点火/ECU、完整的进/排气行为、变速器控制以及标定动力总成仍是各自独立的要求。
