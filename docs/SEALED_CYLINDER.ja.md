# 密閉気筒の基礎

[English](SEALED_CYLINDER.md) · [简体中文](SEALED_CYLINDER.zh-CN.md) · [Français](SEALED_CYLINDER.fr.md) · [Русский](SEALED_CYLINDER.ru.md) · **日本語** · [한국어](SEALED_CYLINDER.ko.md) · [Deutsch](SEALED_CYLINDER.de.md) · [Español](SEALED_CYLINDER.es.md) · [Italiano](SEALED_CYLINDER.it.md) · [Português](SEALED_CYLINDER.pt-BR.md)

`sealed_cylinder` は、剛体のスライダークランクを回転ノードへ結合します。気筒は、比熱比が一定で壁面熱伝達のない、質量が固定された理想気体を含みます。これは圧縮/膨張のベンチマークであり、完全な燃焼エンジンではありません。吸気、排気、燃料、燃焼、漏れ、壁面熱伝達、往復慣性、制御イベントは、別の実装作業のままです。現在のパラメーターはすべて合成値であり、`unverified` です。

初期圧力と温度は、接続されたローターの初期角度に気筒位相を加えた位置で適用されます。その初期角度を変えると、圧力と温度を整合するよう調整しない限り、閉じ込め質量が変わります。ガス状態はクランク位置と不変の初期エントロピーから導出されます。観測可能なチャンネルは増えますが、独立した状態変数は増えません。この縮約が成り立つのは、密閉断熱コンポーネントだけです。

## 幾何とガス状態

長さはメートル、圧力はパスカル、位相はラジアンにコンパイルされます。入力は `m`/`mm`、`pa`/`bar`、`rad`/`deg` を受け付けます。温度はケルビンです。比気体定数は `j_kg_k` を使います。圧縮比とガンマは無次元です。ボアとストロークは正、コンロッド長はストロークの半分を超え、圧縮比とガンマは 1 を超え、初期ガス圧力・温度と気体定数は正でなければなりません。背圧はゼロでもかまいません。

クランク半径 `r = stroke/2`、コンロッド長 `l`、ピストン面積 `A = π bore²/4`、上死点から測った角度 `θ` とします。

```text
x(θ) = r (1 - cos θ) + l - sqrt(l² - r² sin² θ)
Vc   = A stroke / (compression_ratio - 1)
V(θ) = Vc + A x(θ)
```

実装は、上死点付近の桁落ちを避けるため、代数的に等価な形を使います。この幾何は、中心配置の[コロラド州立大学によるスライダークランク容積関係](https://www.engr.colostate.edu/~allan/thermo/page2/page2.html)に従います。

`V0`、`P0`、`T0` を初期状態とします。可逆な理想気体の関係は次のとおりです。

```text
m = P0 V0 / (R T0)
P = P0 (V0/V)^gamma
T = T0 (V0/V)^(gamma-1)
U = P V / (gamma-1)
τ = (P - Pback) dV/dθ
```

圧力/容積と温度の関係は、[NASA の等エントロピー圧縮の導出](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/isentrophic-compression/)に従います。圧縮比 10、ガンマ 1.4 では、下死点から上死点への圧縮で圧力は約 25.119 倍、温度は約 2.512 倍になります。これらは理想化された比であり、実測のエンジン性能ではありません。

## 積分とエネルギー

既存の電気機械の中点求解が、基底解と、気筒ごとに異なる各クランクでのトルクに対する事前計算応答を与えます。縮約された非線形求解が、それらのクランクの角度増分を決めます。同じクランク上の気筒は一つのトルク和に寄与し、連成したクランクはまとめて解きます。物理ティックに、モデルプロバイダー呼び出し、Unity オブジェクト、サードパーティ依存は参加しません。

各気筒は、離散的に仕事と整合するトルクを使います。

```text
τ_discrete Δθ = -(U_next - U_old) - Pback (V_next - V_old)
```

安定な解析的体積の差分商と、小引数の対数/指数評価が、小さな増分と死点通過を扱います。瞬間の `Torque` 出力は `(P-Pback) dV/dθ` のままで、有限ティックの積分に使う平均トルクとは別です。

大域の貯蔵エネルギー変化には、ガス内部エネルギーの変化が含まれます。背圧仕事は外部源仕事 `-Pback ΔV` なので、台帳は `source_work - heat_rejected - stored_energy_change` のままです。シャフトとモーターの散逸は、引き続き熱ネットワークか排出熱に入ります。ガンマが 1 に近づくとき、大きな絶対エネルギー同士を引き算しないよう、ガスエネルギーの変化は直接評価します。

ニュートン反復は 16 回までで、各反復の直線探索は最大 10 回です。線形予測子と受理されたクランク移動量は、ティックあたり 0.25 ラジアン以内に収まる必要があります。非有限値、過大な移動、または収束失敗は `NumericalFailure` を返します。スケジュールされた入力と台帳更新を含む呼び出し全体がロールバックします。より小さい固定ティックで再試行するには、`step_ns` を減らし、モデル/セッションを作り直します。受理は、時間刻みの精度を保証しません。蓄積角度が非常に大きいと、binary64 の角度分解能も失われます。長時間の精度には、それ自身のエビデンスが必要です。

## 観測量と移植可能な実験

各気筒は、圧力 (Pa)、ガス温度 (K)、容積 (m³)、固定質量 (kg)、絶対内部エネルギー (J)、上死点からのピストン変位 (m)、クランクのトルク (N·m) を公開します。チャンネル ID は、既存のオブジェクト/フィールド符号化を保ちます。モデルは忠実度 `sealed_adiabatic_gas` とキャリブレーション `unverified` を報告します。

CLI で `assets/labs/sealed-cylinder.power.json` を実行するか、MCP で `get_example_model({"name":"sealed-cylinder"})` を要求します。サンプルは 100 µs ティック、継続時間 0.2 s、2 回のトルク変更、21 のレポート境界を使います。宣言された KPI は、既存の実験と同様に最終サンプルへ適用されます。コアの保存則検査は、実行全体を通して繰り返される境界を検査します。

同じドキュメントは `SealedCylinder.powerasset` へエクスポートされます。Unity には、変位チャンネルで駆動される模式的なピストン表示があります。シーン単位 1 は全ストロークを表します。物理寸法と出力は SI のままです。実際のエディター、Play Mode、IL2CPP のエビデンスは、まだ未着手です。

`EngineChecks` は、解析幾何と理想気体の検査、2 秒の保存則実行、2 次の刻み細分化、逆回転、小刻み/死点の事例、共有および連成クランク上の複数気筒、電気/熱結合、アトミックな失敗/回復、キャンセル、独立分岐、アセット互換性、ゼロ割り当てのステッピングを実行します。同じ検査は、.NET ホスト上の両方の対象アセンブリに対して実行されます。
