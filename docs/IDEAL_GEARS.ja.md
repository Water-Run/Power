# 理想歯車と遊星の参照

[English](IDEAL_GEARS.md) · [简体中文](IDEAL_GEARS.zh-CN.md) · [Français](IDEAL_GEARS.fr.md) · [Русский](IDEAL_GEARS.ru.md) · **日本語** · [한국어](IDEAL_GEARS.ko.md) · [Deutsch](IDEAL_GEARS.de.md) · [Español](IDEAL_GEARS.es.md) · [Italiano](IDEAL_GEARS.it.md) · [Português](IDEAL_GEARS.pt-BR.md)

`Power.Core` は、不変で割り当てなしの一定負荷参照を 2 つ提供します。`IdealGearPair` と `SimplePlanetaryGear` です。部材速度、角度の進み、反力トルク、外部仕事、運動エネルギー変化、エネルギー残差を返します。連成トランスミッションソルバーに対する、独立した解析的エビデンスです。別の[連成歯車ソルバー](GEAR_NETWORK.ja.md)は、JSON、移植可能アセット、CLI/MCP を通じて恒久の歯車および遊星コンポーネントを公開し、クラッチで制御する変速実験を含みます。参照クラスは、純粋な局所解析解のままです。

## 物理の範囲と符号

理想歯車に、噛み合い慣性、コンプライアンス、バックラッシュ、損失はありません。与えられる慣性はすべて、取り付けられたローターの慣性です。ペアの両方の慣性、または遊星の 3 部材すべてが、正で有限でなければなりません。接地や質量零のノードは、慣性零から推定しません。この抽象化は、Modelica Standard Library の [IdealGear](https://doc.modelica.org/Modelica%204.0.0/Resources/helpWSM/Modelica/Modelica.Mechanics.Rotational.Components.IdealGear.html) と [IdealPlanetary](https://doc.modelica.org/Modelica%204.0.0/Resources/helpWSM/Modelica/Modelica.Mechanics.Rotational.Components.IdealPlanetary.html) の範囲に従います。Power! の実装は独立に書かれており、サードパーティの実装は含まれず、呼ばれもしません。

ペアでは、符号付き比 `r` が次を定義します。

```text
omega_A = r omega_B
reaction_A = lambda
reaction_B = -r lambda
```

正の比はポートの向きを同じにし、負の比は逆にします。反力は**取り付けられたローターに作用する**トルクであり、ローターが歯車へ加えるトルクではありません。適合する運動に対して正味仕事は零です。歯車ペアのハウジングは反力を担い得ます。2 つのローターの通常の角運動量だけが、一般に保存されるわけではありません。一般化運動量 `r J_A omega_A + J_B omega_B` は、一般化された外部トルク `r T_A + T_B` とともに変わります。

単純遊星では、サン、リング、キャリアが 1 つの正の軸を共有します。歯数比 `k = N_ring / N_sun` は 1 を超えなければなりません。運動学的関係と 2 つの独立な自由度は、[MathWorks の遊星歯車の式](https://www.mathworks.com/help/sdl/ref/planetarygear.html)と一致します。

```text
omega_S + k omega_R = (1+k) omega_C
reaction_S = lambda
reaction_R = k lambda
reaction_C = -(1+k) lambda
```

これらの反力の和は零で、正味仕事も零です。モデルは連続な比を受理し、歯数、モジュール、歯の強度、製造可能な幾何は推定しません。遊星の自転/軌道慣性、損失、軸受、潤滑、熱挙動は、この参照の外です。

## 独立した縮約座標の解

ペアの運動は、ポート B を独立座標に使います。

```text
J_equivalent_B = r^2 J_A + J_B
alpha_B = (r T_A + T_B) / J_equivalent_B
alpha_A = r alpha_B
```

遊星は、運動エネルギーの質量行列を作る前にキャリア運動を消去します。`a = 1/(1+k)`、`b = k/(1+k)` として:

```text
omega_C = a omega_S + b omega_R

M = [ J_S + a^2 J_C,    ab J_C        ]
    [ ab J_C,           J_R + b^2 J_C ]

M [alpha_S, alpha_R]^T = [T_S + a T_C, T_R + b T_C]^T
alpha_C = a alpha_S + b alpha_R
```

実装はこの 2×2 行列をスケールし、ほぼ等しい積の引き算を避けるため、行列式を正の項へ展開します。負荷が一定なら加速度は一定なので、速度と変位は浮動小数点の丸めを除いて、厳密な一次/二次の時間積分に従います。反力トルクは、その後、部材の方程式から回復します。テストは、自由な遊星に対して独立した加速度拘束の乗数を使います。期待する解として、縮約行列を再利用しません。

## 状態、単位、失敗の契約

公開プロパティ名は SI 単位を持ちます。kg m2、rad/s、rad、N m、J、秒です。比は無次元です。`Advance` は正で有限な局所時間を取り、`GearStepStatus` を返します。この局所参照の時間は、`Simulation` の有界整数時計を置き換えません。クラスは発展する状態を持ちません。入力は値レコードです。拒否のたびに出力は既定値になり、インスタンスは独立した呼び出し側で共有できます。

初期速度は、すでに関係を満たしていなければなりません。適合性は binary64 のイプシロン `2.2204460492503131e-16` による相対丸めテストを使い、絶対的な低速不感帯はありません。ペアの限界は `64 epsilon (|omega_A| + |r omega_B|)` です。遊星はさらに、2 つの重み付き速度項の大きさを含めるので、打ち消しはキャリア速度を作った演算に対して相対的に扱われます。許容差のオーバーフローを避けるため、項は加算の前にスケールされます。

検証のあと、従属の速度と角度の進みは独立座標から再構成されます。これは受理された丸め残差を除くものであり、有限滑りの係合や同期の計算ではありません。適合しない速度は `IncompatibleState` を返します。実際の速度の不一致には、そのエネルギーを捨てるのではなく、明示的なクラッチ/衝撃モデルを使ってください。歯車の絶対位相は未指定です。報告されるのは角度の進みだけです。

不正な構築パラメーターは、対処可能な引数例外を投げます。非有限、または悪条件のパラメーターの組み合わせは拒否されます。スケールされた遊星の行列式は `64 epsilon` を超えなければなりません。区間の拒否は、不正な時間、不正な状態、適合しない状態、不正なトルク、数値失敗を区別します。算術オーバーフローは `NumericalFailure` を返します。有限な入力だけでは、導出量が表現できるとは限りません。実行時の力の釣り合い検査は、有限だが矛盾した部材反力を残す打ち消しも拒否します。各力の残差は、慣性トルク、加えられたトルク、反力トルクの大きさの和の `512 epsilon` 倍で界されます。受理された端点は、各部材の力積釣り合いも検査します。古い/新しい運動量と、加えられた/反力の力積の大きさの `512 epsilon` 倍を使います。後者は、従属速度の再構成における過剰な打ち消しを検出します。これらの検査が界するのは残差であり、任意の悪条件パラメーターに対する解の誤差ではありません。テストには、有限な打ち消しの失敗と、小さな反力が観測可能なままでなければならない高比のペアが含まれます。残差は `external_work - kinetic_energy_change` です。摩擦熱は作りません。

## 変速状態とエビデンス

テストは、これらの理想的な極限を確立するため、保持またはロックのトルクを明示的に与えます。

| 課した条件 | 結果の速度関係 |
|---|---|
| リングを保持 | `omega_C = omega_S / (1+k)` |
| サンを保持 | `omega_C = k omega_R / (1+k)` |
| キャリアを保持 | `omega_S = -k omega_R` |
| サンをリングへロック | 3 部材の速度がすべて等しい |

与えられたブレーキは、部材が保持されているとき仕事が零です。サン/リングのロックは、反対のトルクを受け、合わせた仕事は零です。これらの検査は静的な変速状態を確立します。この参照は変速、クラッチ係合、油圧回路、TCU を実装せず、任意の外部トルクが部材を自動的に保持することもありません。

同じ 8 つのテストグループが `net10.0` と `netstandard2.1` に対して実行されます。

- 符号付き比と換算慣性。反力動力と、部材ごとの力積釣り合い。
- 独立した力の乗数解に対する、自由な遊星運動。
- 3 つの部材保持の場合と直結。明示的な保持/ロック荷重を伴います。
- 一定負荷の分割不変性と、零を通る速度反転。
- 両方の参照について、独立した積分に対する正弦負荷。区間の半分化は、速度/角度の誤差をおおよそ 4 分の 1 にします。
- 不正な慣性/比/状態/負荷の値、適合しない速度、悪条件、オーバーフロー。
- 各参照について 2,500 の決定的な場合。仕事、運動量、再現性を検査します。
- 各原始素を 10,000 回反復評価し、マネージド割り当ては零。独立した並行呼び出し側による、共有された不変の使用を含みます。

完全な逐次検証の結果は[検証記録](VALIDATION.ja.md)を参照してください。Standard アセンブリのテストは .NET 10 上で実行され、Unity エディター/Play/IL2CPP のエビデンスは提供しません。

## 連成積分

恒久拘束は、電気機械/気筒/クラッチの求解に加わるようになりました。独立したシミュレーション作業領域、完全なロールバック、安定した反力/誤差チャンネルを伴います。JSON/スキーマ、以前のリーダーを持つアセット v8、MCP の発見とリプレイは同じトポロジーを使います。燃焼遊星の実験は、減速/直結の昇段と降段を行います。方程式とエビデンスは[連成契約](GEAR_NETWORK.ja.md)を参照してください。完全な DCT/AT トポロジー、コンバーター、油圧、制御、完全なエンジン挙動、実測の車両キャリブレーションは、Power! の全体目標の一部のままです。
