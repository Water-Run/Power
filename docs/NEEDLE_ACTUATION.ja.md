# 電磁ニードル駆動とサンプリングドーズフィードバック

[English](NEEDLE_ACTUATION.md) · [简体中文](NEEDLE_ACTUATION.zh-CN.md) · [Français](NEEDLE_ACTUATION.fr.md) · [Русский](NEEDLE_ACTUATION.ru.md) · **日本語** · [한국어](NEEDLE_ACTUATION.ko.md) · [Deutsch](NEEDLE_ACTUATION.de.md) · [Español](NEEDLE_ACTUATION.es.md) · [Italiano](NEEDLE_ACTUATION.it.md) · [Português](NEEDLE_ACTUATION.pt-BR.md)

駆動される液体インジェクターは、要求ドーズで理想的な質量ゲートを閉じるのではなく、並進ニードルのリフトを読みます。位置に依存するソレノイド、明示的なニードル質量、戻しばね/減衰、弾性の行程ストッパが運動を供給します。サンプリングドライバーがコイル電圧を所有し、サイクルウィンドウが閉じるか、測定された供給がラッチされた要求に達すると、その指令を止めます。

電流の減衰、機械的な閉じ遅れ、シート反発は、その指令の後も供給を続け得ます。実際の燃料は源/フィルム/ガスの台帳に残ります。要求ドーズは制御目標であり、課された物理的な切断ではありません。これは研究用アクチュエーターと、単純な on/off フィードバックです。非線形な磁気マップ、飽和、ヒステリシス/渦電流損失、温度依存の抵抗、スイッチング/フライバック、電池供給、軸方向の流体力、キャリブレーション済みの噴射は未解決のままです。

## 相反する磁気エネルギーと機械エネルギー

`solenoid` は、供給された一定の巻線抵抗と線形インダクタンスを使います。

```text
L(x) = L_reference + gradient (x - x_reference) > 0
lambda = L(x) i
W_magnetic = lambda^2 / (2 L(x))
d(lambda)/dt = V - R i
F_magnetic = gradient i^2 / 2
```

正のリフトはインダクタンスを増やし、磁気力はその方向に作用します。電流の両方の極性はアーマチュアを吸引します。力は磁気コエネルギーに従います。[Modelica のリラクタンス力ガイド](https://doc.modelica.org/Modelica%204.0.0/Resources/helpWSM/Modelica/Modelica.Magnetic.FluxTubes.UsersGuide.ReluctanceForceCalculation.html)と [Simscape のソレノイド方程式](https://www.mathworks.com/help/simscape-electrical/ref/solenoid.html)が述べるとおりです。Power! は自身の簡約された構成則と積分を使います。Modelica や Simscape への依存は導入されません。インダクタンスは、受理された位置と投機的な位置のすべてで正のままでなければなりません。モデルは負のインダクタンスをクリップせず、欠けた磁気計測をキャリブレーション済みマップで置き換えません。

磁気状態は磁束鎖交です。区間 `h`、端点インダクタンス `L0,L1`、保持された電圧に対し、対称な離散勾配は次を与えます。

```text
A = (1/L0 + 1/L1) / 4
lambda1 = ((1 - h R A) lambda0 + h V) / (1 + h R A)
i_bar = A (lambda0 + lambda1)
F_bar = gradient (lambda0^2 + lambda1^2) / (4 L0 L1)
W_supply = h V i_bar
Q_copper = h R i_bar^2
delta W_magnetic = W_supply - Q_copper - F_bar (x1 - x0)
```

提案された端点位置に対して、磁束は解析的に消去されます。残る力とその位置に関する解析的導関数は、気筒、コンバーター、油圧ピストン、投機的クラッチと同じ非線形機械求解に加わります。受理された運動は、磁束、電気仕事、銅損熱、平均力を一度コミットします。銅損熱は宣言された熱ノードか外部の排出熱に入ります。磁気と機械の貯蔵エネルギーは別のままです。

独立した同時 ODE 積分が、滑らかな 2 次の細分化を検証します。静止した RL 極限にも、解析的な電流参照があります。エネルギー共役なステッピングは、それだけでは粗い時間刻みでの正確な運動を確立しません。電気的時定数、行程の移動、接触イベントは、なお分解能を必要とします。

## ニードル質量、ばね、弾性ストッパ

ニードルは、kg、m、m/s を持つ通常の並進ノードです。通常の `linear_spring` が、明示的な熱の経路とともに予荷重と減衰を供給します。`travel_stop` は、公称行程の限界に可逆な片側エネルギーを加えます。

```text
E_stop = K/2 [max(0,x_min-x)^2 + max(0,x-x_max)^2]
```

その離散反力は、受理された端点の間のエネルギーの負の勾配です。侵入は位置をクランプするのではなく、エネルギーを蓄えます。解析的導関数は機械求解を共有します。区間あたりの公称行程の移動は、スパンの 4 分の 1 に制限されます。スライダのストッパ所有者は一人で、油圧ピストンがすでに所有するストッパも含みます。油圧/ソレノイドの座標を共有することは可能で、各力が同じ座標に寄与します。

シート反発は、この弾性簡約の中では物理的です。一つのスナップショットで開度がゼロでも、後の区間全体で流量がゼロである証明にはなりません。接触減衰、シール摩擦、衝突の反発係数、実測のシート/ニードル挙動は未解決のままです。

## 物理的な開度と供給

`liquid_fuel_injector` 上の任意の `parameters.needle` は、並進の `needle_node` と、m/mm の `closed_position` および `full_open_position` を含みます。実際の開度は、有界な線形リフト比です。

```text
opening = clamp((x - x_closed)/(x_full_open - x_closed), 0, 1)
```

受動的な[液体レール/ノズル則](LIQUID_FUEL_INJECTION.ja.md)は、その有効開度で圧力ヘッドを積分します。有限な在庫と圧力エネルギーの限界は保ちますが、要求ドーズで物理的な供給に上限を掛けたり、クランクウィンドウが閉じる/逆転するときに流れを消したりはしません。開いたニードルは、クランクが止まっていても、要求ドーズがゼロでも、燃料を入れられます。クランクウィンドウは、フィードバックのために目標履歴をなおラッチします。新しく観測されたウィンドウの外の供給は、最新の観測サイクルと総量の履歴の一部のままです。

`needle` がなければ、以前の理想的な割当制限インジェクター経路が保持され、モデルのフィンガープリントとリプレイは変わりません。ニードルを備えたモデルは、異なる忠実度を宣言します。このインクリメントでニードルは圧力平衡です。軸方向の圧力/噴流力は推論されません。既存の、液体体積を無視できる受け側は、その排除圧力仕事を明示的に送り出します。

## 整数クロックのドライバーと入力の所有

`needle_driver` は、駆動されるインジェクター、そのソレノイド、同じタイミングクランクを指名します。物理ティックに揃い、1 秒以下の、明示的で正の `sample_period_ns` と、V の正の `drive_voltage` を必要とします。所有されるコイルは電圧ゼロから始まります。到来した各サンプルで、ドライバーはラッチされたドーズと実際に供給された質量を記録し、前進ウィンドウに残りの目標供給がある間は駆動電圧を保持します。そうでなければ電圧ゼロを保持します。

ドライバーはソレノイドの電圧チャンネルを所有します。エージェントはインジェクターの `kg` 要求を書きます。電圧への直接書き込みは `controlled_input` を返し、書き込み可能な指令チャンネルを特定し、状態とリビジョンを保持します。初期書き込みとイベント書き込みは、制御履歴を進めません。サンプリング位相は整数のシミュレーション時刻に従います。このドライバーは、ピーク/ホールド電流制御、予測的な閉じ補償、PWM/フライバック、完全な ECU/TCU 挙動を実装しません。

## 定義、チャンネル、トランザクション

| コンポーネント | パラメーターとポート |
|---|---|
| `solenoid` | 並進の A ノード。V 入力。非負のオーム抵抗、正の H の基準インダクタンス、H/m の勾配（`h_m`）、m/mm の基準位置、A の初期電流。任意の熱シンク |
| `travel_stop` | 並進の A ノード。増加する m/mm の限界と、正の N/m 剛性 |
| `needle_driver` | 回転タイミングの A ノード。安定したインジェクター/ソレノイド ID、整数のサンプル周期、V の駆動レベル |

定義は、無関係な量、誤った単位/領域、無効な初期インダクタンス、重複したストッパ/電圧の所有、一致しないニードル/コイル/クランク、揃っていないサンプル周期を拒否します。Core クライアントは `SolenoidCoil`、`StrokeStop`、`NeedleDrive`、`InjectorNeedleDefinition`、独立した磁気/接触の法則を使います。

ソレノイドの出力は、瞬間の `current`、直前ティックの離散平均 `force`、磁気の `internal_energy`、累積の `copper_heat`、電気の `source_work` を公開します。ストッパの出力は、弾性エネルギーと瞬間反力を公開します。ドライバーの出力は、保持された `command_voltage` と、直前サンプルの要求/供給ドーズを公開します。インジェクターの `opening` は実際の位置開度で、直前ティックの平均供給も実際のものです。すべての ID と単位は、検証とセッション作成を通して発見できます。

ソレノイドあたり四つの報告状態エントリと、ドライバーあたり三つが、有界な状態予算に加わります。磁束、平均力、補償された熱/仕事、サンプルされた制御状態、保持された入力、ニードル/ストッパ、すべての源/相の履歴は、完全なシミュレーションとともにコピー、ハッシュ、ロールバックされます。成功したアクティブなステッピングとスナップショットは、マネージドメモリを割り当てません。キャンセル、失敗したバッチ、独立した分岐は、電気、機械、熱、制御器の履歴をまとめて保持します。

アセット v20 は、型付きの磁気、ストッパ、ニードル、ドライバーの表を加え、v1-v19 リーダーを保持します。有界な長さ/個数、ダイジェスト、単位、区別された所有、偽造ダウングレード保護が検査されます。本物の v19 液体噴射フィクスチャは、フィンガープリントと、同じランタイムでのアップグレードされたリプレイを保ちます。[ASSET_FORMAT.ja.md](ASSET_FORMAT.ja.md) を参照してください。

## 実験と受理

`needle-actuated-cylinder` は、アクチュエーターとサンプリングフィードバックを、有限レール/フィルムの燃焼気筒へ接続します。その 0.6 s の境界は、最後の閉じ/蒸発の過渡の間、液体フィルムを保持し得ます。乾いたフィルムや正確な目標供給を仮定するのではなく、源/フィルム/ガス/反応の完全な在庫が検証されます。JSON、移植可能アセット、実際の MCP 子サーバーは、同じ定義とリプレイを共有します。

孤立したアクチュエーターは 8 mg を要求し、電流減衰、閉じ運動、その後の小さなシート反発を通した過剰供給を観測します。それらの量は研究結果であり、キャリブレーション済みのインジェクタータイミングや、受理されたドーズ追従制御器ではありません。[VALIDATION.ja.md](VALIDATION.ja.md) が数値エビデンスと限界を記録します。用意された Unity のコイル、ストッパ、制御器、スケールされたニードル表示は、なお実際のエディター/Play 検証を必要とします。完全なパワートレイン、実測の駆動、精密化した磁気/電子/流体力、レール補給、ECU/TCU は未完了のままです。
