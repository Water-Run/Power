# 准稳态变矩器网络

[English](CONVERTER_NETWORK.md) · **简体中文** · [Français](CONVERTER_NETWORK.fr.md) · [Русский](CONVERTER_NETWORK.ru.md) · [日本語](CONVERTER_NETWORK.ja.md) · [한국어](CONVERTER_NETWORK.ko.md) · [Deutsch](CONVERTER_NETWORK.de.md) · [Español](CONVERTER_NETWORK.es.md) · [Italiano](CONVERTER_NETWORK.it.md) · [Português](CONVERTER_NETWORK.pt-BR.md)

`torque_converter` 参与同一套轴、电机、气缸、离合器和理想齿轮求解。泵轮与涡轮是带显式惯量的不同转动节点。导轮是静止的地面;其反作用可观测,但不做功。流体损失进入可选热节点或外部排热账本。一个分开的并联 `clutch` 提供锁止。实验室中的全部参数都是合成的,且为 `unverified`。

## 显式图谱与方程

需要四张图谱:`pump_positive`、`pump_negative`、`turbine_positive` 和 `turbine_negative`。绝对速度较大的构件是参考驱动件;恰好相等时泵轮胜出。该构件的符号选择其正/负图谱。这是数学上的参考构件约定,反向旋转时也一样。它不推断不可用的倒车或滑行特性。

对驱动件速度 `wD` 和从动件速度 `wF`,`s = wF/wD` 位于 `[-1,1]`。每张图谱包含 2–32 个显式点,无量纲 `speed_ratio`、`torque_ratio` R,以及单位为 `nm_s2_rad2` 的 `capacity_coefficient` C。C 乘以速度的平方;它不是 K 系数的倒数。R 与 C 线性插值,且从不外推。两个速度都为零时反作用为零,模式为零。

```text
Tdriver   = -C(s) * wD * abs(wD)
Tfollower =  R(s) * C(s) * wD * abs(wD)
Tstator   = -(Tpump + Tturbine)
Qdot      = C(s) * abs(wD)^3 * (1 - s*R(s))
```

编译要求严格递增的结点覆盖 `[-1,1]`,C/R 非负,并且在每一段上全程 `s*R(s) <= 1`。只检查结点不够:R 对 s 线性会使效率成为二次;任何内部极大值也会被检查。斜率必须有限。在 `s=1` 处,C 必须为零且 R 为一,从而在同向等速时流体扭矩为零。在 `s=-1` 处,泵轮正/涡轮负图谱与泵轮负/涡轮正图谱必须给出匹配的物理反作用。这防止参考构件在反向旋转中切换时出现跳跃。端点比较只允许 `64*epsilon*(abs(a)+abs(b))` 的舍入容差。图谱数组被拥有且不可变;归一化系数进入模型指纹。

这些限制定义 Power! 当前的被动有符号图谱模型。它们不声称覆盖任意实测变矩器曲线。一般的基于图谱的驱动/滑行约定由 [MathWorks Torque Converter](https://www.mathworks.com/help/sdl/ref/torqueconverter.html)及其[双模式示例](https://de.mathworks.com/help/sdl/ug/torque-converter-two-mode.html)记录。四张有符号图谱、插值校验和下面的求解器是 Power! 的设计;没有从那些参考复制源代码或实测参数集。

## 耦合积分与限制

变矩器反作用使用区间中点速度。存在气缸时,联合牛顿系统求解其离散曲轴转角功和两个变矩器端口速度。每一个单位扭矩响应都包含机电系统和永久齿轮投影。离合器约束迭代调用同一个非线性求解;捕获和反向细分会重新生成区间响应。没有在气缸或离合器积分之后再施加的滞后变矩器扭矩。

非线性求解每次迭代有 24 次迭代和 12 次折半线搜索尝试。气缸角度残差容差为 `2e-14 rad`。变矩器速度残差使用 `2e-12 + 64*epsilon*(abs(value)+abs(free_prediction)) rad/s`。解析的分段图谱雅可比和有限差分的气缸功导数构成联合系统。现有的 0.25 rad 气缸行程、气门/燃烧分辨率、离合器迭代/事件和齿轮约束限制仍然适用。在现有的 32 节点、64 组件和 64 状态预算内,至多支持八个变矩器。每个变矩器增加四个逻辑可观测历史状态:两个平均扭矩、平均热功率和累计热量。补偿热求和也参与复制/哈希/回滚。

被接受区间的热量为 `-h*(Tp*wp_mid + Tt*wt_mid)`,因此被移除的机械功就是所记录的热量。超出已求解速度舍入容差的负热量拒绝该区间;只有舍入量级的负残差被钳位为零。扭矩和热功率在被接受的内部区间上按时长加权,再除以完整节拍。试探性事件尝试从不提交其热量或反作用。失败或取消的批次会回滚全部变矩器、离合器、齿轮、气体、燃烧历史、输入和全局账本状态。分支拥有自己的工作区。测试检验无分配捕获。

对光滑的独立变矩器运动,中点积分是二阶。耦合的点火模型保留显式壁温耦合和区间平均离合器脱离,因此不声称在所有过渡上都有统一的二阶。数值失败或精度研究时请细化节拍;重建会话之前先检查图谱斜率、惯量/速度尺度和离合器约束。有效图谱并不保证每一个选定的时间步都可解。

## 共享模型与可观测契约

JSON 使用必需的 `node_a`(泵轮)、`node_b`(涡轮)、`parameters` 下的四个数组,以及可选的 `heat_node`。它不接受变矩器输入通道、行星架端口或隐式图谱默认值。`ComponentDefinition.TorqueConverter` 暴露同一个 Core 模型。图谱错误带有组件 ID 和可操作字段,例如 `converter.pump_positive` 或 `converter.counter_rotation`。

| 字段 | 含义 | 单位 |
|---|---|---|
| `torque` | 最近一个完整节拍的平均泵轮扭矩 | Nm |
| `torque_at_b` | 最近一个完整节拍的平均涡轮扭矩 | Nm |
| `torque_at_c` | 最近一个完整节拍的平均静止导轮反作用 | Nm |
| `heat_flow` | 最近一个完整节拍的平均流体热功率 | W |
| `fluid_heat` | 累计被接受的流体热 | J |
| `speed_ratio` | 当前从动件/驱动件的有符号速比;停止时为零 | fraction |
| `converter_drive` | 0 停止,1 泵轮正,2 泵轮负,3 涡轮正,4 涡轮负 | 状态码 |

平均扭矩/功率从零开始。边界输入更新不改写前一节拍的平均输出。这里的 `torque_at_c` 命名导轮反作用;该组件没有第三转子。含变矩器的模型通告 `quasisteady_converter_powertrain`,并增加指纹标签 10。不含变矩器的模型指纹和轨迹保持不变。可移植资产 v10 保留全部四张图谱;v1–v9 读取器和真实夹具仍然保留。

## 实验室与证据

请求 MCP 示例 `fired-converter`,或运行:

```sh
dotnet src/Power.Cli/bin/Release/net10.0/Power.Cli.dll assets/labs/fired-converter.power.json --output artifacts/reports/fired-converter.json
```

这个 0.8 s 实验室从 600 rpm 的泵轮和 300 rpm 的涡轮开始,驱动行星排的太阳轮和 3:1 主减速。齿圈制动选择减速;太阳轮/齿圈离合器选择直接驱动。独立排程的锁止、释放和再捕获检验流体路径与摩擦路径。这些是给定事件,不是自动变速器控制器。

在 50,000 ns 节拍下,全部 87 个报告边界经 CLI、可移植资产和 MCP 精确回放。模型指纹为 `839d03901973668d`,最终状态哈希为 `834a679376b7a6fd`。最终泵轮/涡轮转速约为 73.37748 rad/s,负载转速 6.988331 rad/s,流体热 24.27663 J,锁止热 22.84709 J。换挡离合器和制动另加 157.18199 J 与 83.42289 J。共享热节点达到 301.438643 K;总能量残差约为 `3.30e-11 J`。这些数字描述一次合成瞬态。

独立测试覆盖解析的 `C(s)=k(1-s), R=1` 双惯量解、解析失速衰减、二阶细化、热与外部热路径、导轮平衡、倒车/滑行/反向旋转状态、共享变矩器端口、齿轮折算、锁止、整批回滚、取消、分支和零分配。点火模型细化用最终速度、流体热和锁止热的无量纲组合距离对照一次 3,125 ns 运行,使用五种节拍大小。它还把绝对差分别限制在 0.0002 rad/s 或 J 以下。在事件附近,单项热量误差不必在每一次减半时都下降。这一检查与独立解析阶分开。有符号图谱的所有权/校验,以及重新签名的畸形可移植记录,有专门检查。

[液压网络](HYDRAULIC_NETWORK.zh-CN.md)现在提供由压力导出的锁止和换挡容量。流体角动量、变矩器充液/压力动力学、旋转/自由轮导轮力学、随温度变化的物性、泵/调节器与活塞动力学、完整的 DCT/AT 拓扑以及 ECU/TCU 协调仍然开放。完整的发动机行为、OEM 测量和车辆标定也仍然开放。Studio 有示意流体端口和已准备的测试;实际的编辑器/Play/IL2CPP 证据仍然分开,且在本环境中不可用。
