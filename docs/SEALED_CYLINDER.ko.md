# 밀폐 실린더 기초

[English](SEALED_CYLINDER.md) · [简体中文](SEALED_CYLINDER.zh-CN.md) · [Français](SEALED_CYLINDER.fr.md) · [Русский](SEALED_CYLINDER.ru.md) · [日本語](SEALED_CYLINDER.ja.md) · **한국어** · [Deutsch](SEALED_CYLINDER.de.md) · [Español](SEALED_CYLINDER.es.md) · [Italiano](SEALED_CYLINDER.it.md) · [Português](SEALED_CYLINDER.pt-BR.md)

`sealed_cylinder`는 강체 슬라이더-크랭크를 회전 노드에 결합합니다. 실린더에는 비열비가 일정한 이상 기체의 고정 질량이 있고, 벽 열전달은 없습니다. 이것은 압축/팽창 벤치마크이지, 완전한 점화 엔진이 아닙니다. 흡기, 배기, 연료, 연소, 누설, 벽 열전달, 왕복 관성, 제어 이벤트는 별도의 구현 작업으로 남아 있습니다. 현재 매개변수는 모두 합성이며 `unverified`입니다.

초기 압력과 온도는 연결된 로터의 초기 각에 실린더 위상을 더한 곳에 적용됩니다. 그 초기 각을 바꾸면, 압력과 온도를 일관되게 맞추지 않는 한 포획 질량이 바뀝니다. 가스 상태는 크랭크 위치와 불변 초기 엔트로피에서 유도됩니다. 관측 가능한 채널은 더하지만 독립 상태 변수는 없습니다. 이 축소는 밀폐 단열 컴포넌트에만 유효합니다.

## 기하와 가스 상태

길이는 미터로, 압력은 파스칼로, 위상은 라디안으로 컴파일됩니다. 입력은 `m`/`mm`, `pa`/`bar`, `rad`/`deg`를 받습니다. 온도는 켈빈이고, 비기체 상수는 `j_kg_k`를 씁니다. 압축비와 gamma는 무차원입니다. 보어와 행정은 양수여야 하고, 커넥팅 로드 길이는 행정의 절반보다 커야 하며, 압축비와 gamma는 1보다 커야 하고, 초기 가스 압력과 온도, 기체 상수는 양수여야 합니다. 배압은 0일 수 있습니다.

크랭크 반경 `r = stroke/2`, 커넥팅 로드 길이 `l`, 피스톤 면적 `A = π bore²/4`, 상사점에서 잰 각 `θ`에 대해:

```text
x(θ) = r (1 - cos θ) + l - sqrt(l² - r² sin² θ)
Vc   = A stroke / (compression_ratio - 1)
V(θ) = Vc + A x(θ)
```

구현은 상사점 근처의 상쇄를 피하도록, 대수적으로 동등한 형태를 씁니다. 이 기하는 중심 정렬된 [콜로라도 주립대학교의 슬라이더-크랭크 체적 관계](https://www.engr.colostate.edu/~allan/thermo/page2/page2.html)를 따릅니다.

`V0`, `P0`, `T0`가 초기 상태입니다. 가역 이상 기체 관계는 다음과 같습니다.

```text
m = P0 V0 / (R T0)
P = P0 (V0/V)^gamma
T = T0 (V0/V)^(gamma-1)
U = P V / (gamma-1)
τ = (P - Pback) dV/dθ
```

압력/체적 관계와 온도 관계는 [NASA의 등엔트로피 압축 유도](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/isentrophic-compression/)를 따릅니다. 압축비 10, gamma 1.4에서 하사점에서 상사점으로 압축하면 압력은 약 25.119배, 온도는 약 2.512배가 됩니다. 이것은 이상화된 비이며, 측정된 엔진 성능이 아닙니다.

## 적분과 에너지

기존의 전기기계 중점 해석이 기본해와, 서로 다른 각 실린더 크랭크에서 토크에 대한 사전 계산된 응답을 제공합니다. 축소된 비선형 해석이 그 크랭크들의 각 증분을 정합니다. 같은 크랭크의 실린더는 하나의 토크 합에 더해지고, 결합된 크랭크는 함께 풀립니다. 모델 공급자 호출, Unity 객체, 제3자 의존성은 물리 틱에 참여하지 않습니다.

각 실린더는 일과 일관된 이산 토크를 씁니다.

```text
τ_discrete Δθ = -(U_next - U_old) - Pback (V_next - V_old)
```

안정적인 해석적 체적 분할 차분과, 인수가 작을 때의 로그/지수 평가가 작은 증분과 사점 통과를 처리합니다. 순간 `Torque` 출력은 `(P-Pback) dV/dθ`로 남습니다. 유한 틱을 적분하는 평균 토크와는 다릅니다.

전역 저장 에너지 변화에는 가스 내부 에너지 변화가 포함됩니다. 배압 일은 외부 원천 일 `-Pback ΔV`이므로, 장부는 `source_work - heat_rejected - stored_energy_change`로 남습니다. 축과 모터의 소산은 여전히 열 네트워크나 방출열로 들어갑니다. gamma가 1에 가까울 때 큰 절대 에너지를 빼지 않도록, 가스 에너지 변화는 직접 평가합니다.

뉴턴 반복은 16회로 제한되고, 반복마다 직선 탐색은 최대 10회입니다. 선형 예측기와 수용된 크랭크 이동은 틱당 0.25라디안 안에 있어야 합니다. 비유한 값, 과도한 이동, 수렴 실패는 `NumericalFailure`를 반환합니다. 예약된 입력과 장부 갱신을 포함한 호출 전체가 롤백됩니다. `step_ns`를 줄이고 모델과 세션을 다시 만들어, 더 작은 고정 틱으로 다시 시도하세요. 수용이 시간 스텝의 정확성을 보장하지는 않습니다. 누적 각이 매우 크면 binary64 각도 분해능도 잃습니다. 긴 시간의 정확성에는 별도의 증거가 필요합니다.

## 관측량과 이식 가능한 실험

각 실린더는 압력(Pa), 가스 온도(K), 체적(m³), 고정 질량(kg), 절대 내부 에너지(J), 상사점으로부터의 피스톤 변위(m), 크랭크 토크(N·m)를 노출합니다. 채널 ID는 기존의 객체/필드 인코딩을 유지합니다. 모델은 충실도 `sealed_adiabatic_gas`와 교정 `unverified`를 보고합니다.

CLI로 `assets/labs/sealed-cylinder.power.json`을 실행하거나, MCP로 `get_example_model({"name":"sealed-cylinder"})`을 요청하세요. 샘플은 100 µs 틱, 지속 0.2 s, 토크 변화 두 번, 보고서 경계 21개를 씁니다. 선언된 KPI는 기존 실험과 같이 최종 샘플에 적용됩니다. 코어 보존 검사는 실행 전체에서 반복된 경계를 검사합니다.

같은 문서는 `SealedCylinder.powerasset`으로 내보내집니다. Unity에는 변위 채널이 구동하는 개략 피스톤 뷰가 있습니다. 씬 단위 하나가 전체 행정을 나타냅니다. 물리 치수와 출력은 SI로 남습니다. 실제 편집기, Play Mode, IL2CPP 증거는 아직 남아 있습니다.

`EngineChecks`는 해석 기하와 이상 기체 검사, 2초 보존 실행, 2차 스텝 세분화, 역회전, 작은 스텝/사점 사례, 공유 크랭크와 결합 크랭크의 다중 실린더, 전기/열 결합, 원자적 실패/복구, 취소, 독립 분기, 자산 호환, 할당 0 스텝을 실행합니다. 같은 검사가 .NET 호스트의 두 대상 어셈블리에 대해 실행됩니다.
