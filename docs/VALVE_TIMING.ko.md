# 크랭크각 밸브 타이밍

[English](VALVE_TIMING.md) · [简体中文](VALVE_TIMING.zh-CN.md) · [Français](VALVE_TIMING.fr.md) · [Русский](VALVE_TIMING.ru.md) · [日本語](VALVE_TIMING.ja.md) · **한국어** · [Deutsch](VALVE_TIMING.de.md) · [Español](VALVE_TIMING.es.md) · [Italiano](VALVE_TIMING.it.md) · [Português](VALVE_TIMING.pt-BR.md)

`gas_orifice`의 선택적 `valve_timing`은 개방에 주기적인 크랭크각 포락을 곱합니다. 같은 Core, JSON, CLI, MCP, 이식 가능한 자산 정의로 고정 가스 용기와 가동 실린더를 지원합니다. 포락은 가속, 정지, 역전 동안의 실제 크랭크 위치를 따릅니다. 이것은 유효 유동 면적을 나타냅니다. 캠 접촉, 물리적 밸브 양정, 스프링 힘, 마찰은 모델링하지 않습니다.

## 계약과 위상

```json
"valve_timing": {
  "crank_node": 1,
  "cycle_angle": { "value": 720, "unit": "deg" },
  "open_angle": { "value": 520, "unit": "deg" },
  "duration_angle": { "value": 200, "unit": "deg" }
}
```

`crank_node`는 회전 노드를 가리켜야 합니다. 세 각에는 모두 명시적 `deg` 또는 `rad` 단위가 필요합니다. 사이클 각은 정확히 360도 또는 720도입니다. 지속은 1e-6라디안에서 사이클 각 사이입니다. 개방 각은 유한하며, 사이클에 대한 나머지로 정규화됩니다. 음의 각과, 사이클 경계를 넘는 로브가 지원됩니다. 여러 밸브가 하나의 크랭크를 참조할 수 있으며, 겹치는 로브도 포함됩니다.

위상은 참조된 크랭크의 각에 대한 상대이며, 그 초기 위치도 포함됩니다. 실린더의 기하 위상은 자동으로 **더해지지 않습니다**. 작성자가 각 실린더에 맞는 밸브 개방 각을 골라야 합니다. 720도 사이클은 이어지는 크랭크 회전을 구분합니다. 피스톤 위치, 속도, 경과 시간에서 추론되는 암묵적 4행정 위상은 없습니다.

사이클 `C`, 개방 각 `a`, 지속 `D`, 최대 개방 `u`, 크랭크 각 `theta`에 대해:

```text
s = modulo(theta - a, C)       // [0, C) 안
opening = u sin²(pi s / D)     // 0 < s < D
opening = 0                   // 그 외, 양쪽 경계 포함
A_effective = A_orifice * opening
```

이 프로파일과 그 1차 도함수는 로브 경계에서 연속입니다. 역회전은 그것을 되밟습니다. 정지한 크랭크는 현재 개방을 유지하며, 흐름을 계속할 수 있습니다. 개방은 흐름 방향을 고르지 않습니다. 기존의 압력 구동 양방향 오리피스 법칙이 그대로 적용됩니다. 유량 계수는 별도의 승수로 남습니다.

타이밍된 유동 제한에서 `initial_input`과 선택적 입력 채널은 [0, 1] 분율인 **최대 개방**을 지정합니다. 채널량은 `peak_opening`입니다. 0은 로브를 끕니다. 출력량 `effective_opening`은 `Field.Opening`(JSON KPI 필드 `opening`)을 쓰고, 실제 분율을 보고합니다. `mass_flow`는 그 분율로 평가됩니다. 타이밍되지 않은 유동 제한은 기존 입력량과 의미론을 유지합니다. 예약된 최대 개방 변경과 대화형 변경은 원자적 입력 검증과 개정 검사를 유지합니다.

## 적분과 복구

타이밍된 모델은, 독립 크랭크가 구동하는 고정 용기를 포함해, 대칭인 가스 반 스텝 / 크랭크 일 전체 스텝 / 가스 반 스텝 적분을 씁니다. 전반은 구간의 시작 크랭크 각을, 후반은 결과 각을 씁니다. 가스 솔버는 각 반 스텝 안에서 자기 질량/에너지 동역학을 풉니다. 밸브 가장자리를 연속적으로 찾거나, 바깥 기계 틱을 적응시키지는 않습니다.

활성 로브마다 바깥 틱은 다음을 만족해야 합니다.

```text
limit = min(0.25 rad, D / 8)
max(abs(theta_next - theta_old), dt * max(abs(omega_old), abs(omega_next))) <= limit
8 * binary64_epsilon * max(abs(theta_old), abs(theta_next)) <= limit
```

끝점 속도 한계는 순 각 변화가 작은 역전도 포함합니다. 정밀도 한계는, 펼친 각이 로브에 필요한 분해능을 잃지 않게 합니다. 분해능이 부족한 틱은 양쪽 끝점이 닫혀 있어도 실패합니다. 좁은 개방 전체를 조용히 건너뛸 수 없습니다. 꺼진 최대 개방은 로브 분해능을 요구하지 않습니다. 이것은 수치 가드이지, 오차 허용이나 임의의 동역학에 대한 보장이 아닙니다.

실패는 `NumericalFailure` / `numerical_failure`를 반환하고, 이전 틱과 예약 입력을 포함한 호출자 배치의 어떤 부분도 커밋하지 않습니다. `step_ns`를 줄이고 모델과 세션을 다시 만드세요. 이벤트가 여전히 새 틱에 맞는지 확인하세요. 초기 각이 매우 크면, 연결된 모든 컴포넌트의 위상과 일관된 동등 각을 고르세요. 기존의 실린더 한계와 가스 한계도 적용됩니다. 숨은 가변 캠 상태는 더해지지 않습니다. 크랭크 위치와 최대 개방 입력은 이미 스냅샷, 해시, 분기에 참여합니다.

매끄럽고 벽이 없는 기준 사례는 2차 수렴을 보입니다. 벽 온도는 바깥 틱에 걸쳐 고정되므로, 벽에 결합된 모델은 1차로 남습니다. 기존의 평형 근처 유동 제한은 국소 차수를 낮출 수 있습니다. 보존과 리플레이만으로 시간 정확성이 입증되지는 않습니다.

## 증거와 호환

검사에는 해석적 포락 값, 명시적 사이클, 위상 순환, 가속, 역전, 정지한 크랭크, 꺼진 최대 개방, 분해되지 않은 로브 전체 통과, 취소, 배치 전체 롤백, 독립 분기, 할당 없는 스텝/스냅샷이 포함됩니다.

고정 용기 블로다운 시험은 사인 제곱 노출을 독립적으로 적분하고, 닫힌 형식의 단열 초킹 방출 해를 씁니다. 전진과 역전 모두 틱 세분화에서 수렴합니다. 별도의 가동 실린더 시험은 질량, 내부 에너지, 크랭크 운동, 각에 의존하는 유동 제한을 독립적으로 작성된 RK4 ODE로 적분하고, 로브 경계 둘을 모두 넘습니다. 기준 세분화가 자기 정확성을 세운 뒤에 Core 결과와 비교합니다. 문턱은 [검증](VALIDATION.ko.md)을 참고하세요.

타이밍된 모델만 지문 태그 6, 대상 컴포넌트/크랭크 ID, 정규화된 프로파일 매개변수를 더합니다. 타이밍되지 않은 모델은 이전 지문과 스텝을 유지합니다. 자산 v5는 유계 타이밍 기록을 더하고 v1–v4 판독기를 유지합니다. 더 이전의 진본 픽스처가 지문과 업그레이드된 리플레이를 검사합니다. [자산 레이아웃](ASSET_FORMAT.ko.md)을 참고하세요.

[크랭크 타이밍 실린더 실험실](../assets/labs/crank-timed-cylinder.power.json)은 합성 챔버를, 흡기와 배기 프로파일이 있는 반복 720도 사이클로 모터링합니다. 예약된 토크 변화 두 번이 크랭크 속도를 바꿉니다. 밸브 타이밍 자체에는 시간 일정이 없습니다. JSON/CLI, MCP, 자산 재생이 63개 보고서 경계 모두에서 일치합니다. 빌드는 `CrankTimedCylinder.powerasset`을 내보냅니다. 스튜디오는 유효 개방 채널로 개략 표식을 애니메이션합니다. 편집기/Play/IL2CPP 실행은 아직 남아 있습니다.

Cantera의 [내연 반응기 예](https://cantera.org/stable/examples/python/reactors/ic_engine.html)는 크랭크각 포트 제어의 개념적 참고입니다. 그 고정 속도 가정, 밸브 법칙, 예제 매개변수는 Power! 솔버의 교정이나 검증으로 채택되지 않습니다. 이 구현은 프로젝트의 보존적 크랭크 결합과 양방향 노즐 법칙을 씁니다. 별도의 [예혼합 연소](PREMIXED_COMBUSTION.ko.md)가 이제 연료와 화학 에너지 수지를 더합니다. 모든 샘플 매개변수는 `unverified`로 남습니다. 완전한 엔진 동작과 실측 차량 교정은 아직 열려 있습니다.
