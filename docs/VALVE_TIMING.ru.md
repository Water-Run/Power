# Фазы клапанов по углу коленвала

[English](VALVE_TIMING.md) · [简体中文](VALVE_TIMING.zh-CN.md) · [Français](VALVE_TIMING.fr.md) · **Русский** · [日本語](VALVE_TIMING.ja.md) · [한국어](VALVE_TIMING.ko.md) · [Deutsch](VALVE_TIMING.de.md) · [Español](VALVE_TIMING.es.md) · [Italiano](VALVE_TIMING.it.md) · [Português](VALVE_TIMING.pt-BR.md)

Необязательный `valve_timing` на `gas_orifice` умножает его открытие на периодическую
огибающую по углу коленвала. Он поддерживает неподвижные газовые сосуды и подвижные цилиндры через те же
определения Core, JSON, CLI, MCP и переносимого актива. Огибающая следует фактическому
положению коленвала при разгоне, остановке и реверсе. Она представляет эффективную
площадь потока; контакт кулачка, физический подъём клапана, силы пружин и трение она не моделирует.

## Контракт и фаза

```json
"valve_timing": {
  "crank_node": 1,
  "cycle_angle": { "value": 720, "unit": "deg" },
  "open_angle": { "value": 520, "unit": "deg" },
  "duration_angle": { "value": 200, "unit": "deg" }
}
```

`crank_node` должен указывать на вращательный узел. Все три угла требуют явных единиц `deg`
или `rad`. Угол цикла — ровно 360 или 720 градусов; длительность лежит между 1e-6
радиан и углом цикла. Угол открытия конечен и нормализован по модулю цикла.
Отрицательные углы и лепесток, пересекающий границу цикла, поддерживаются. Несколько клапанов
могут ссылаться на один коленвал, в том числе с перекрывающимися лепестками.

Фаза отсчитывается от угла указанного коленвала, включая его начальное положение.
Фаза геометрии цилиндра **не** добавляется автоматически: автор должен выбрать
подходящий угол открытия клапана для каждого цилиндра. Цикл 720 градусов различает
последовательные обороты коленвала. Неявной четырёхтактной фазы, выведенной из
положения поршня, скорости или прошедшего времени, нет.

Для цикла `C`, угла открытия `a`, длительности `D`, пикового открытия `u` и угла коленвала `theta`:

```text
s = modulo(theta - a, C)       // in [0, C)
opening = u sin²(pi s / D)     // 0 < s < D
opening = 0                   // otherwise, including both boundaries
A_effective = A_orifice * opening
```

Этот профиль и его первая производная непрерывны на границах лепестка. Обратное
вращение проходит его вспять; остановившийся коленвал удерживает текущее открытие и может продолжать течение.
Открытие не выбирает направление потока: по-прежнему действует существующий двунаправленный
закон отверстия, движимый давлением. Его коэффициент расхода остаётся отдельным множителем.

Для фазированного сужения `initial_input` и его необязательный входной канал задают **пиковое
открытие**, долю в [0, 1]. Величина канала — `peak_opening`; ноль отключает
лепесток. Выходная величина `effective_opening` использует `Field.Opening` (поле KPI в JSON
`opening`) и сообщает фактическую долю. `mass_flow` вычисляется с этой долей.
Сужения без фаз сохраняют прежнюю входную величину и семантику. Запланированные и
интерактивные изменения пика сохраняют атомарную проверку входа и проверки ревизии.

## Интегрирование и восстановление

Фазированные модели используют симметричное интегрирование: газовый полушаг / полный шаг работы коленвала / газовый полушаг,
включая неподвижный сосуд, который ведёт независимый коленвал. Первый полушаг
использует угол коленвала в начале, второй — получившийся угол. Газовый решатель
разрешает собственную динамику массы и энергии внутри каждого полушага. Он не ищет непрерывно
кромки клапана и не адаптирует внешний механический тик.

Для каждого активного лепестка внешний тик должен удовлетворять:

```text
limit = min(0.25 rad, D / 8)
max(abs(theta_next - theta_old), dt * max(abs(omega_old), abs(omega_next))) <= limit
8 * binary64_epsilon * max(abs(theta_old), abs(theta_next)) <= limit
```

Ограничение по скорости на концах покрывает и реверс, у которого чистое изменение угла мало.
Ограничение точности не даёт развёрнутому углу потерять разрешение, нужное
его лепестку. Недостаточно разрешённый тик завершается неудачей, даже если оба конца закрыты; он не может
молча пропустить целое узкое открытие. Отключённый пик разрешения лепестка не требует.
Это численные предохранители, а не допуск погрешности и не гарантия для произвольной динамики.

Отказ возвращает `NumericalFailure` / `numerical_failure` и не фиксирует никакую часть
пакета вызывающего, включая более ранние тики и запланированные входы. Уменьшите `step_ns` и создайте
модель или сессию заново; события по-прежнему должны попадать на новый тик. Для очень больших начальных
углов выберите эквивалентный угол, согласованный с фазой каждого связанного компонента.
Существующие пределы цилиндра и газа также применяются. Скрытое изменяемое состояние кулачка не добавляется;
положение коленвала и пиковые входы уже участвуют в снимках, хешах и ветвлениях.

Гладкие эталоны без стенки показывают сходимость второго порядка. Температуры стенок
остаются фиксированными на внешнем тике, поэтому модели со связью со стенкой остаются первого порядка. Существующее
ограничение течения вблизи равновесия может снижать локальный порядок. Сохранение и повтор сами
по себе не демонстрируют точность по времени.

## Свидетельства и совместимость

Проверки включают аналитические значения огибающей, явные циклы, обход фазы по модулю, разгон,
реверс, неподвижный коленвал, отключённые пики, неразрешённые пересечения целого лепестка, отмену,
полный откат пакета, независимые ветвления и шаги и снимки без выделений.

Тест опорожнения неподвижного сосуда независимо интегрирует выдержку sin² и использует
замкнутое решение адиабатического критического расхода. И прямой, и обратный случаи
сходятся при уточнении тика. Отдельный тест подвижного цилиндра интегрирует массу, внутреннюю
энергию, движение коленвала и сужение, зависящее от угла, независимо написанными ОДУ RK4,
пересекая обе границы лепестка. Уточнение эталона сначала устанавливает его собственную точность,
и только затем сравниваются результаты Core. Пороги см. в [валидации](VALIDATION.ru.md).

Только фазированные модели добавляют тег отпечатка 6, идентификаторы целевого компонента и коленвала и нормализованные
параметры профиля. Модели без фаз сохраняют прежние отпечатки и шаги. Актив v5
добавляет ограниченные записи фаз и сохраняет читатели v1–v4; подлинные более ранние фикстуры проверяют
отпечатки и повтор после обновления. См. [раскладку актива](ASSET_FORMAT.ru.md).

[Лаборатория цилиндра с фазами по коленвалу](../assets/labs/crank-timed-cylinder.power.json)
прокручивает синтетическую камеру через повторяющиеся циклы 720 градусов с профилями впуска и выпуска.
Два запланированных изменения момента меняют скорость коленвала; у самих фаз клапанов
расписания по времени нет. JSON/CLI, MCP и воспроизведение актива совпадают на всех 63 границах отчёта.
Сборка экспортирует `CrankTimedCylinder.powerasset`; Studio анимирует схематичные маркеры
по каналам эффективного открытия. Выполнение Editor/Play/IL2CPP ещё не проведено.

[Пример реактора внутреннего сгорания Cantera](https://cantera.org/stable/examples/python/reactors/ic_engine.html)
— концептуальная отсылка к управлению окнами по углу коленвала. Его предположения постоянной скорости,
закон клапана и параметры примера не приняты как калибровка или верификация
решателя Power!. Эта реализация использует сохраняющую связь с коленвалом проекта
и двунаправленный закон сопла. Отдельное [premixed-сгорание](PREMIXED_COMBUSTION.ru.md)
теперь добавляет учёт топлива и химической энергии. Все параметры образцов остаются `unverified`;
полное поведение двигателя и измеренная калибровка автомобиля остаются открытыми.
