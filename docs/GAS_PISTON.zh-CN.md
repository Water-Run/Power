# 线性气体活塞与液压蓄能器

[English](GAS_PISTON.md) · **简体中文** · [Français](GAS_PISTON.fr.md) · [Русский](GAS_PISTON.ru.md) · [日本語](GAS_PISTON.ja.md) · [한국어](GAS_PISTON.ko.md) · [Deutsch](GAS_PISTON.de.md) · [Español](GAS_PISTON.es.md) · [Italiano](GAS_PISTON.it.md) · [Português](GAS_PISTON.pt-BR.md)

`gas_piston` 把一个平动质量接到一个有限气体腔。腔室的质量、内能、压力和温度仍是实际仿真状态。其容积来自活塞几何,而不是固定储存容积。气体孔口和壁面热链可以使用同一个腔室。

把气体活塞和液压活塞放在同一个平动节点上,就形成气体支承的蓄能器隔膜。两种压力力在联合求解中作用在一个质量和一个位移上。回位弹簧、阻尼和柔性行程端部仍是显式组件。这是集总活塞蓄能器,具有恒定有效液体柔度和定比热理想气体。气囊几何、密封摩擦、气体溶解、气蚀、磨损和 OEM 标定不在其内。

## 几何、压力与功

面积 A 和参考容积 Vr 为正。参考位置 xr 是显式的,压缩方向 s 为 +1 或 -1:

```text
gas volume       V(x) = Vr - s*A*(x-xr)
absolute pressure p  = (gamma-1)*U/V
gas temperature   T  = U/(m*cv)
force on slider      = -s*A*(p-p_reference)
```

`p_reference` 是显式绝对压力,包括为零的声明真空。组成蓄能器时,它提供液体表压约定所用的油箱参考。它不从气体预充推断。初始气体压力和温度、气体常数 R 和 gamma 来自气体节点;其初始质量为 `p_initial*V_initial/(R*T_initial)`。

在机械区间内,封闭气体功遵循 `U_next=U_old*(V_old/V_next)^(gamma-1)`。力使用恰好给出这一离散能量传递的平均压力。参考压力功为 `p_reference*s*A*dx`,并进入外部源功。于是气体内能加上隔膜的机械能平衡流体功、参考功和显式损失。气体储存可提供的表压能量使用 `Delta U - reference_work`;仅有绝对气体能量会高估该传递。

对相对容积变化 z,压力因子为 `phi=(1-(1+z)^(1-gamma))/((gamma-1)*z)`。其极限值为一,极限导数为 `-gamma/2`。小行程使用缩放级数,否则使用稳定的对数/指数差。力雅可比是解析的。反向和对置气体腔共享同一坐标,并保持有符号的容积/功约定。

气体流动和热使用现有的对称流动/功/流动分裂。封闭腔室保持绝热不变量;显式壁温处理保留现有的一阶壁面耦合精度。气体质量流按储气边界的焓记账,而不是把加入的质量当成无能量。没有多方拟合或等温覆盖代替能量状态。

## 契约与数值边界

| 参数 | 含义 |
|---|---|
| `node_a` | 带正质量的平动节点 |
| `node_b` | 有一个运动容积所有者的气体腔;省略节点 `storage` |
| `area` | 正面积,单位 m2 或 mm2 |
| `reference_volume` | 正容积,单位 m3 或 liters |
| `reference_position` | 该容积处的位置,单位 m 或 mm |
| `reference_pressure` | 非负绝对压力,单位 Pa 或 bar |
| `compression_direction` | +1(默认方向)或 -1 |

一个气体腔有一个几何所有者;几个不同的腔可以作用在一个质量上。气体活塞没有直接输入或热汇覆盖。请使用显式力源、连接的液压活塞、气体孔口或气体热链。观察腔室质量/能量/压力/温度,以及组件容积、滑块力和来自参考压力的 `source_work`。

气体容积必须保持为正,包括在共享液压活塞的整个名义行程上。一个被接受的机械区间至多改变当前气体容积的 25%。大行程、非正容积或未解析的力拒绝整批。重试前请减小节拍,并检查几何、质量、压力和力的尺度。运动和能量不被钳位。柔性端部侵入仍储存显式止挡势能,并仍受正气体容积约束。

物理/控制状态、气体存量和全部历史共享取消、完整回滚、哈希和独立分支。资产 v16 保留四个几何/参考量和压缩方向。JSON、CLI 和 MCP 暴露同一套定义。Studio 隔膜/腔室视图和导入/Play 测试以 C# 9 源码准备;实际的编辑器和 Player 证据仍然分开。

## 蓄能器实验与证据

`gas-accumulator-pump` 在电动泵、机械滑阀旁通和压力离合器上增加一个 50 ml 初始气体腔、一个 50 g 隔膜、显式黏性阻尼和柔性端部。气体从绝对压力 200 kPa 和 300 K 开始;参考压力为 100 kPa。隔膜以 0.1 mm 的柔性落座侵入开始,使其预充与零液体表压平衡。所有取值都是研究参数。3–4 s 的电压/需求脉冲显式打开充油和排油两条路径;储存的气体能量和扫过的液体容积随后下降,然后充能恢复。

[MathWorks Gas-Charged Accumulator (IL)](https://www.mathworks.com/help/hydro/ref/gaschargedaccumulatoril.html)描述气/液分离以及充能/放能机理。Power! 组合自己的有限能量气体端口和机械/液压端口,而不是复制固定多方指数、参数默认值或实现代码。

检查包括解析绝热功和导数、小行程、带光滑二阶细化的分开质量/能量 RK4 瞬态、对置腔室、共有的气/液运动、有限壁面 RK4 细化、运动容积的气体流入、独立的能量/容积账目和完整事务。没有输运或热的封闭、未混合腔室在状态校验之后跳过多余的零速率积分。这一测得的优化保留每一个边界值与哈希;稳态步进和快照读取分配零托管字节。详细误差界限、计时和平台范围在 [VALIDATION.md](VALIDATION.zh-CN.md)。
