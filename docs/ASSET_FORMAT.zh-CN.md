# 模型资产

[English](ASSET_FORMAT.md) · **简体中文** · [Français](ASSET_FORMAT.fr.md) · [Русский](ASSET_FORMAT.ru.md) · [日本語](ASSET_FORMAT.ja.md) · [한국어](ASSET_FORMAT.ko.md) · [Deutsch](ASSET_FORMAT.de.md) · [Español](ASSET_FORMAT.es.md) · [Italiano](ASSET_FORMAT.it.md) · [Português](ASSET_FORMAT.pt-BR.md)

`power.model.v1` JSON 是编写输入。`.powerasset` 文件为其他运行时携带模型与实验数据。`Power.Assets` 不依赖 JSON 库、Unity 或第三方包,并与核心一起为 .NET 10 和 .NET Standard 2.1 编译。

CLI 的 `export` 命令与 MCP 的 `export_model_asset` 工具使用同一个编码器。Unity 的 `ScriptedImporter` 把文件导入为 `PowerModelAsset`,并且只序列化数据字节。运行时解码这些字节,再次编译模型,不加载任意代码或已存储的 LU 分解。默认资产由 `tools/Build.cs` 生成,并可以从 JSON 重建。

```mermaid
flowchart LR
    JSON[power.model.v1 JSON] --> ENC[CLI export 或 export_model_asset]
    ENC --> FILE[.powerasset]
    FILE --> UNI[Unity ScriptedImporter]
    UNI --> RE[解码、重新编译、校验指纹]
```

## 当前版本 24 与保留的读取器

编码器写出 `power.asset.v24`;版本 1 到 24 仍可读取。计数表与记录大小仍是 v23 的那些。种类 37 是 `carrier_gear`:其基线速比有限、有符号且非零;其 8 字节齿轮扩展保留元件索引与彼此不同的运动行星架。带类型的计数覆盖每一个行星架啮合。重新封装摘要的 v23 降级会拒绝这个新种类。

行星架啮合增加指纹标签 28、补偿坐标、端点约束一致性,以及带累积反作用的有界相对投影细化。普通转子记录保留绝对行星自转与行星架轨道惯量总量。一份真实的 v23 简化 Ravigneaux 夹具保留其摘要/指纹与精确的升级后回放。参见 [分解行星](RESOLVED_PLANETS.zh-CN.md)。

## 保留的版本 1 布局

每个整数与每个 IEEE 754 binary64 值都是小端。文件最多 1 MiB。字符串是严格的 UTF-8。

| 顺序 | 数据 |
|---|---|
| 标识 | 8 个 ASCII 字节 `POWERAST`,然后是 int32 格式版本 `1` |
| 模型与时间 | uint64 模型指纹、节拍纳秒数、实验时长、采样间隔 |
| 溯源 | uint16 名称字节数、名称、源 JSON 的 32 字节 SHA-256 |
| 计数 | 四个 int32 值:节点、元件、输入更改、KPI |
| 描述符 | 每个节点 44 字节,每个元件 156 字节,按对象 ID 排序 |
| 输入 | 每次更改 24 字节:uint64 时间、uint64 通道、double 值 |
| KPI | 每条 33 字节:uint32 对象、int32 字段、一个边界标志字节、三个 double 界限 |
| 完整性 | 此前每一个字节的 SHA-256,32 字节 |

节点与元件字段顺序遵循 `src/Power.Assets/AssetCodec.cs` 中的版本 1 编解码器。在分配描述符数组之前检查计数、精确文件长度与摘要。接下来验证单位、拓扑、时间、事件与 KPI,并把指纹与当前求解器所编译的模型比较。不匹配就需要重新导出。

名称最多 128 个 UTF-16 码元,并且不含控制字符。模型限制为 32 个节点、64 个元件与 128 个状态。实验最多一小时、一千万个节拍、10,000 个输入时刻、65,536 次输入更改与 256 个 KPI。整数商 `duration / sample_every` 不得超过 10,000,并且 1 MiB 文件限制仍然适用。事件位于 `[0, duration)` 内,按绝对时间排序,对齐到节拍,并且不在同一时刻重复一个通道。

尾部摘要检测损坏。它不是溯源认证。导出结果中的 `asset_sha256` 是整个文件的摘要,包括该尾部字段。`source_sha256` 标识编写文档。模型指纹标识编译语义。步长改变之后再次导出可以保持原始源摘要,同时仍然改变模型指纹。合成参数保持 `unverified`。

`AssetPlayback` 在时刻零应用初始事件,并在每次 `Advance` 内使用核心的原子事件批量。失败与取消保持时间、状态与事件游标。一次调用最多推进一百万个节拍。调用方拆分更长的运行。CLI 报告边界、资产回放与一次实时 MCP 导出已经相互核对。Unity 编辑器、Mono 与 IL2CPP 执行证据仍然欠缺。
