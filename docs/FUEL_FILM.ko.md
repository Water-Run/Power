# 유한 액체 연료 필름과 증발

[English](FUEL_FILM.md) · [简体中文](FUEL_FILM.zh-CN.md) · [Français](FUEL_FILM.fr.md) · [Русский](FUEL_FILM.ru.md) · [日本語](FUEL_FILM.ja.md) · **한국어** · [Deutsch](FUEL_FILM.de.md) · [Español](FUEL_FILM.es.md) · [Italiano](FUEL_FILM.it.md) · [Português](FUEL_FILM.pt-BR.md)

`fuel_film`은 추적되는 가스 수신기 옆에 명시적 초기 액체 재고를 저장합니다. 유한 열 노드가 현열과 상변화 열을 공급합니다. 증발한 연료는 수신기의 질량, 내부 에너지, 연료 구성 성분에 합류합니다. 기존의 예혼합 반응은 증기만 소비합니다. 액체 재고는 분사된 연료가 아니라 초기 습윤이며, 총질량과 화학 에너지 장부의 일부로 남습니다.

이것은 액체 변위 체적이 무시할 만하고 포화 온도가 규정된, 일정 물성 연구 모델입니다. 액체 레일, 니들 또는 분무 동역학, 압력 의존 상평형, 응축, 다성분 연료 물성, 교정된 가솔린 거동은 구현하지 않습니다.

## 상 에너지와 유한 열원

`c_l`을 액체 비열, `c_v`를 수신기 가스의 정적 비열, `T_s`를 선언된 포화 온도, `L_u > 0`을 `T_s`에서의 증기 빼기 액체 비내부에너지 차라고 합니다. 공유 열 기준은 다음과 같습니다.

```text
e_offset = (c_v - c_l) T_s - L_u
U_liquid = m_liquid (c_l T_liquid + e_offset)
U_vapor_added = delta_m c_v T_s
```

`L_u`는 증발 엔탈피가 아니라 J/kg의 내부 에너지 차입니다. 공급된 엔탈피는 여기에 쓰기 전에, 명시적이고 근거 있는 변환이 필요합니다. 이 기준에서 액체 열 에너지는 음일 수 있습니다. 온도와 질량은 여전히 물리적으로 허용되어야 합니다. 화학 에너지 `m_liquid * LHV`는 별도이며, 반응 열이나 외부 원천 일을 만들지 않고 증기와 함께 전달됩니다.

포화 아래에서 컨덕턴스 `K`는 액체 용량 `m_liquid c_l`을 유한 벽 용량 `C_w`에 결합합니다. 온도 차는 속도 `K (1 / (m_liquid c_l) + 1 / C_w)`로 해석적으로 감쇠합니다. 용량으로 가중한 평균 온도는 일정하게 남습니다. 액체가 `T_s`에 닿으면, 법칙이 그 시각을 풀고 남은 구간을 증발에 씁니다.

포화에서 `T_wall > T_s`이면, 벽 과열은 속도 `K / C_w`로 감쇠합니다. 구간 `h`의 가용 상 열은 `C_w (T_wall - T_s) (1 - exp(-K h / C_w))`이고, `m_liquid L_u`로 상한이 있습니다. 필름은 마를 때까지 `T_s`에 머뭅니다. 증발 질량은 상 열을 `L_u`로 나눈 값입니다. 건조가 끝나면 액체 질량과 에너지가 정확히 0이 되고, 열 인출이 멈춥니다. 차가운 벽은 기존 액체를 식힐 수 있습니다. 수신기 증기를 응축하지는 않습니다.

모든 전달은 `delta U_liquid + U_vapor_added = Q_from_wall`을 만족합니다. 벽은 같은 열을 잃으므로, 상변화가 외부 에너지 경계를 도입하지 않습니다. 음이 아닌 연료 재고와 전체 구성 성분 장부는 총에너지 장부와 독립적으로 검사됩니다.

## 그래프와 문서 계약

| 데이터 | 요건 |
|---|---|
| `node_a` | 명시적 예혼합 연료 추적과 LHV가 있는 유한 가스 수신기 |
| `node_b` | 양의 용량과 온도가 있는 유한 열 벽 |
| `initial_mass` | 음이 아닌 kg. 완전한 초기 액체 재고 |
| `initial_temperature` | 양의 K, 포화 이하 |
| `liquid_specific_heat` | 양의 J/(kg K), JSON 단위 `j_kg_k` |
| `saturation_temperature` | 양의 K, JSON 단위 `k` |
| `latent_internal_energy` | 양의 J/kg, JSON 단위 `j_kg` |
| `conductance` | 음이 아닌 W/K, JSON 단위 `w_k` |

JSON은 여섯 매개변수를 모두 요구합니다. 필름에는 입력 채널, 크랭크 타이밍, 별도 열 싱크가 없습니다. 관련 없는 매개변수, 잘못된 포트 도메인, 단위, 비유한 값, 지원되지 않는 상태 용량은 거부됩니다. Core 호출자는 `ComponentDefinition.LiquidFilm`과 `FuelFilmDefinition`을 씁니다. 독립 `EquilibriumFuelFilm` 법칙은 허용되는 상태 생성과 유한 욕 진행을 노출합니다.

각 필름은 컴파일러의 유계 상태 예산에 보고 상태 항목 다섯을 기여합니다. 질량, 열 에너지, 증발 이력, 평균 흐름, 벽 열과 그 보정 이력은 시뮬레이션이 소유합니다. 취소, 거부된 입력, 늦은 솔버 실패, 독립 분기, 투기적 클러치 구간은 완전한 트랜잭션을 보존합니다. 성공한 스텝과 스냅샷 읽기는 워밍업 뒤에 관리 메모리를 할당하지 않습니다.

## 적분 정확성

수용된 구간은 필름 / 가스 / 기계·반응 / 가스 / 필름 반 스텝을 씁니다. 벽을 공유하는 필름은 가스 진행 전에 안정된 컴포넌트 순서로 실행되고, 뒤에는 역순입니다. 유한 벽 온도는 필름 서브스텝 사이에 이어지고, 벽 열은 같은 열 해석에 들어갑니다.

고립된 유한 욕 법칙은 현열 가열, 포화, 건조에 걸쳐 해석적입니다. 독립적인 동시 ODE 적분이, 다른 벽 열원 없이, 벽을 공유하는 필름 둘과 초킹 가스 출구로 수송되는 증기에 대해 매끄러운 2차 세분화를 확인합니다. 가스 열 링크와 다른 열원은 여전히 명시적인 바깥 구간의 벽 온도를 읽으므로, 그 결합은 1차 정확성을 유지합니다. 반응 창, 밸브 이벤트, 건조는 자기 세분화 검사가 필요합니다. 정확한 배치 리플레이만으로, 점화 파워트레인의 시간 스텝 정확성이나 균일한 2차가 증명되지는 않습니다.

## 관측량과 이식 가능한 의미론

| 필름 필드 | 의미 |
|---|---|
| `mass` | 남은 액체 연료, kg |
| `temperature` | 액체 온도. 말랐을 때는 선언된 포화 온도 |
| `internal_energy` | 선언된 상 기준에서의 부호 있는 액체 열 에너지, J |
| `chemical_energy` | 남은 액체 연료의 화학 에너지, J |
| `evaporated_fuel_mass` | 누적 공급 증기, kg |
| `mass_flow` | 마지막 완전한 물리 틱에 걸친 평균 증기 공급, kg/s |
| `film_wall_heat` | 벽에서 인출한 누적 열, J. 냉각이면 음이 될 수 있음 |
| `heat_flow` | 순간 `K (T_wall - T_liquid)`, W. 말랐을 때는 0 |

출력 ID와 단위는 검증 또는 세션 생성으로 탐색하세요. 전역 질량, 연료, 화학 에너지 관측량에는 필름 재고가 포함됩니다. 내부 증기 공급은 저장소 연료 에너지나 외부 엔탈피를 늘리지 않습니다.

자산 v19는 모든 상 물성을 저장하고 v1-v18 판독기를 유지합니다. 필름마다 형식이 있는 64바이트 상 기록 하나가 필요합니다. 유계 길이/개수, 다이제스트, 완전한 적용 범위, 중복/누락 기록, 단위, 물리 컴파일, 다운그레이드 보호가 검사됩니다. 진본 v17 연료 계량 픽스처는 지문과, 같은 런타임의 업그레이드된 리플레이를 유지합니다. [ASSET_FORMAT.ko.md](ASSET_FORMAT.ko.md)를 참고하세요.

## 실험실과 남은 작업

`film-fired-cylinder`는 처음에 젖은 필름을 가열하고, 공기를 따로 들이며, 쓸 수 있는 증기를 규정 Wiebe 연소로 소비합니다. 유한한 뜨거운 벽이 상 열을 부담합니다. 액체는 직접 타지 않습니다. JSON, CLI, 이식 가능한 리플레이, 실제 MCP 서버가 모든 보고서 경계에서 일치합니다. 소스, 스키마, 세션 계약은 공유된 채로 남습니다. 매개변수는 `unverified`입니다.

측정된 수치 증거는 [VALIDATION.ko.md](VALIDATION.ko.md)를 참고하세요. 준비된 Unity 필름 표식과 수명 주기 검사는 여전히 실제 편집기/Play 검증이 필요합니다. 별도의 [액체 인젝터](LIQUID_FUEL_INJECTION.ko.md)가 이제 유한 컴플라이언트 공급원에서 필름을 보충합니다. 펌프/보충, 니들/분무, 실측 연료 물성, 점화/ECU, 완전한 흡기/배기 동작, 변속기 제어, 교정된 파워트레인은 별도 요건으로 남아 있습니다.
