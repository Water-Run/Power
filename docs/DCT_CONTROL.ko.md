# 샘플링 듀얼 클러치 동기화와 단계적 인계

[English](DCT_CONTROL.md) · [简体中文](DCT_CONTROL.zh-CN.md) · [Français](DCT_CONTROL.fr.md) · [Русский](DCT_CONTROL.ru.md) · [日本語](DCT_CONTROL.ja.md) · **한국어** · [Deutsch](DCT_CONTROL.de.md) · [Español](DCT_CONTROL.es.md) · [Italiano](DCT_CONTROL.it.md) · [Português](DCT_CONTROL.pt-BR.md)

`dct_controller`는 [7단 전진/후진 연구 그래프](DUAL_CLUTCH_TRANSMISSION.ko.md)의 구동 클러치 두 개와 셀렉터 채널 여덟 개를 소유합니다. 정수인 요청 기어 명령은 확인된 실제 기어, 선택된 경로, 변속 단계, 측정된 동기화 오차, 제어기 결함과 분리되어 있습니다.

이것은 명시적 토크 단절이 있는, 센서가 구동하는 연구용 상태 기계입니다. 완전한 TCU/ECU 토크 블렌딩, 상세한 도그/보크 링이나 클러치 액추에이터 거동, 교정된 변속 전략, 완전한 차량 결함 관리를 세우지는 않습니다.

## 상태와 물리적 확인

| 단계 | 유지되는 명령 정책과 전환 |
|---|---|
| 중립 | 두 구동 클러치와 셀렉터가 모두 해제됨 |
| 준비 | 대상인 반대 경로는 무부하로 사전 선택되고, 앞선 구동은 체결된 채로 유지 |
| 해제 | 앞선 구동의 개방이 램프 다운되고, 대상 구동은 해제된 채로 유지 |
| 동기화 | 두 구동이 해제된 상태에서 대상 셀렉터가 완전 개방까지 램프하고, 측정된 슬립과 물리적 잠금을 기다림 |
| 체결 | 대상 구동이 램프 업되고, 다른 구동은 해제된 채로 유지 |
| 구동 | 확인된 대상 구동/셀렉터. 인접한 무부하 경로의 사전 선택이 허용됨 |
| 결함 | 두 구동과 모든 셀렉터가 해제됨. 중립이나 다른 요청이 있을 때까지 결함을 유지 |

인계가 진행되는 동안 대상은 래치됩니다. 그 이후의 비중립 요청은 그 인계 뒤에 처리됩니다. 중립은 도래한 샘플에서 중단합니다. 같은 입력 경로의 변경은 셀렉터를 바꾸기 전에 그 구동을 해제합니다. 반대 입력 경로의 변경은 구동 해제 전에 무부하 대상을 준비할 수 있습니다. 각 경로는 셀렉터를 최대 하나만 명령하고, 명령된 구동 클러치의 겹침은 쓰지 않습니다.

셀렉터 개방 램프는 설정된 체결 지속 시간을 씁니다. 셀렉터는 완전 명령, 공급된 허용 오차 안의 측정 슬립, 물리적 `Locked` 모드 이후에만 준비됩니다. 구동은 완전 체결 명령, 작은 구동 슬립, 물리적 잠금 이후에만 확인됩니다. 명령을 받아들였다고 해서 순시 비나 물리적 기어 완료를 알리지는 않습니다.

비활성 사전 선택은 확인된 경로를 잠깐 흔들 수 있습니다. 구동이나 선택된 경로가 물리적으로 잠겨 있지 않으면 스냅샷의 실제 기어는 0입니다. 지속적 상실은 따로 시간을 잽니다. 제어기는 일시적인 샘플 하나를 지속된 결함과 혼동하지 않습니다. 그 타이머는 단계가 바뀌거나 회복되면 재설정됩니다.

## 요청 기어, 방향, 결함

요청 기어는 `[-1,7]`의 정수입니다. 0은 중립이고 -1은 후진입니다. 정적, 즉시, 예정 입력 검증은 분수를 거부합니다. 소스 명령은 명시적 `state_code` 단위를 씁니다. 일반 클러치 분율을 기어 번호로 해석하지 않습니다.

동기화 시간 초과는 관측 가능한 무부하 결함을 반환합니다. 공급된 속도 한계를 넘는 양의 차량 운동에 대한 후진 요청, 또는 음의 운동에 대한 전진 요청은 방향 전환 결함으로 막힙니다. 확인된 구동/셀렉터 잠금의 지속적 상실은 같은 공급 시간 초과와 별개의 결함 코드를 씁니다. 이 제어기 결과는 물리 정책 상태이지, 수치 실패나 암시적인 성공 변속 KPI가 아닙니다.

| 결함 코드 | 의미 |
|---:|---|
| 0 | 결함 없음 |
| 1 | 동기화/체결 시간 초과 |
| 2 | 차량 운동 때문에 막힌 방향 전환 요청 |
| 3 | 확인된 잠금의 지속적 상실 |

중립은 결함을 지우고 트레인을 해제합니다. 다른 유효한 요청은 새 시도를 시작할 수 있습니다. 같은 실패 대상을 반복해서 내도 샘플마다 시간 초과가 재설정되지는 않습니다. 더 높은 수준의 결함 결정, 타당성 검사, 센서 실패, 운전자/차량 안전 기능은 별도 작업으로 남아 있습니다.

## 정의와 소유권

제어기는 엔진 A 노드, 차량 노드, 홀수/짝수 구동 클러치 ID, 전진 1-7/후진 순서의 셀렉터 여덟 개, 요청 기어 입력을 선언합니다. 액추에이터 채널 열 개는 서로 다르고, 처음에 해제되어 있으며, 소유자가 하나여야 합니다. 컴파일러는 보통 클러치 종류, 축/허브/종감속 토폴로지, 홀수/짝수 할당, 후진 아이들러 경로, 안정 참조를 검증합니다. 셀렉터 목록은 불변 정의/컴파일 데이터로 복사됩니다.

명시적 타이밍은 샘플, 해제, 체결, 동기화 시간 초과의 나노초입니다. 샘플링은 물리 틱에 맞춥니다. 다른 시간은 양의 샘플 배수이며 최대 10초입니다. 동기화 허용 오차와 방향 속도 한계는 `rad_s` 또는 `rpm`을 씁니다. OEM 값, 액추에이터 맵, 손실 곡선은 조용히 공급되지 않습니다.

에이전트는 요청 기어를 씁니다. 구동/셀렉터에 직접 쓰면 올바른 명령 이름/채널과 함께 `controlled_input`을 반환하고, 개정/상태는 바꾸지 않습니다. 읽기는 실시간 요청, 확인된 기어, 명령된 홀수/짝수 선택, 단계, 대상 셀렉터 슬립, 결함을 노출합니다. 이 상태 코드와 물리 채널은 서로 다른 의미를 유지합니다.

## 정수 시계와 완전한 트랜잭션

샘플은 유계 정수 시뮬레이션 시간에서 실행됩니다. 입력 쓰기는 제어 메모리를 진행하지 않습니다. 유지된 분율은 보통의 물리 솔버에 적용됩니다. 관성, 기어 반력, 동기화 열, 구동 열은 기존 장부에 남습니다. 제어기 상태에는 래치된/활성 기어, 선택, 단계/결함, 단계 시계, 측정 오차, 지속 잠금 타이머가 들어 있습니다. 분기, 취소, 늦게 실패한 배치, 시험적 구간은 그 메모리와 유지된 모든 명령을 함께 복사/해시/롤백합니다. 성공한 진행과 스냅샷은 관리형 메모리를 할당하지 않습니다.

긴 제어 기어 실행은 중점 속도에서 온 보정된 좌표 증분을 씁니다. 그 보정은 트랜잭션으로 처리되고 해시됩니다. 엄격한 위상 허용 오차는 바뀌지 않습니다. 이것은 새로운 장기 부하 동기화 시나리오가 드러낸 누적 반올림 오차를 해결합니다. 더 이전 모델 경로는 앞선 적분과 리플레이 동작을 유지합니다.

보고된 상태 한도는 명시적으로 **128**이며, 노드 32개와 컴포넌트 64개는 바뀌지 않습니다. 이것으로 이전 64 상태 한계를 넘는, 완전한 연구용 점화/DCT/제어기 조합이 가능합니다. 정확한 경계의 컴파일/진행과, 한계를 넘는 물리/제어기 모델이 검사됩니다. 빌드와 테스트는 직렬로 남습니다.

## 이식 가능성과 공유 실험

자산 v22는 DCT 제어기마다 형식이 지정된 104바이트 경로/타이밍/허용 오차 레코드를 하나 더합니다. v1-v21 판독기, 안정된 선행 ID, 유계 개수/길이, 다이제스트, 형식 있는 소유권, 단위, 물리 컴파일 검사를 유지합니다. 제어기 모델은 지문 태그 26을 더합니다. 요청/실제/선택/단계/오차/결함 필드는 선행 ID를 바꾸지 않고 뒤에 붙습니다. 진본 v21 그래프 픽스처는 다이제스트와 같은 런타임의 업그레이드된 리플레이를 유지합니다.

`controlled-dual-clutch`는 일곱 경로 전부와 선택된 하단 변속에 기어 요청을 냅니다. 명목 시간을 가정하지 않고, 물리적 완료를 통해 최종 인계와 비활성 사전 선택을 관측합니다. `controlled-fired-dual-clutch`는 같은 샘플링 정책을 개방 실린더 예혼합 연소와 결합합니다. JSON, CLI, 이식 가능한 리플레이, 실제 MCP 자식 서버가 정의를 공유합니다.

[VALIDATION.ko.md](VALIDATION.ko.md)는 상태/인터록, 결함/회복, 소유권, 정수 입력, 불변 경로, 용량, 긴 위상 유지, 보존, 완전한 리플레이 증거를 기록합니다. 모든 매개변수는 `unverified`로 남습니다. 토크 블렌딩, 완전한 액추에이터/센서/ECU 거동, 완전한 AT, 실제 Unity, 교정된 대상 파워트레인은 아직 끝나지 않았습니다.
