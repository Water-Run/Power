# 결합 클러치 시뮬레이션

[English](CLUTCH_NETWORK.md) · [简体中文](CLUTCH_NETWORK.zh-CN.md) · [Français](CLUTCH_NETWORK.fr.md) · [Русский](CLUTCH_NETWORK.ru.md) · [日本語](CLUTCH_NETWORK.ja.md) · **한국어** · [Deutsch](CLUTCH_NETWORK.de.md) · [Español](CLUTCH_NETWORK.es.md) · [Italiano](CLUTCH_NETWORK.it.md) · [Português](CLUTCH_NETWORK.pt-BR.md)

관리형 `clutch` 컴포넌트는 두 회전 노드를 잇거나, 로터 하나를 접지에 잇습니다. 기존의 전기기계/실린더 풀이에 참여하고, 생성된 마찰열을 열 노드나 외부 열 장부로 보냅니다. JSON, CLI, MCP, 자산 v10, Studio는 같은 정의를 씁니다. 이것은 변속기 결합 요소를 구현합니다. 완전한 DCT/AT 토폴로지, 펌프/피스톤 동역학, ECU/TCU 협조는 별도 작업으로 남아 있습니다. [유압 네트워크](HYDRAULIC_NETWORK.ko.md)는 이제 압력으로 작동하는 클러치 변형을 구동합니다. [맵 기반 컨버터](CONVERTER_NETWORK.ko.md)는 이제 이 풀이를 공유하고, 록업에는 별도의 병렬 클러치를 씁니다.

[드라이 클러치 물리 계약](CLUTCH_PHYSICS.ko.md)은 쿨롱 법칙과, 일정 부하 아래 독립적인 두 관성의 정확한 기준을 정의합니다. 아래 그래프 솔버는 그 법칙을 결합 네트워크로 확장합니다. 엔진 토크나 모터 전류를 클러치에 대한 단방향 입력으로 얼려 두지는 않습니다.

## 정의와 채널

```json
{
  "id": 16,
  "kind": "clutch",
  "node_a": 1,
  "node_b": 4,
  "heat_node": 5,
  "input_channel": 104,
  "initial_input": { "value": 0, "unit": "fraction" },
  "parameters": {
    "static_capacity": { "value": 100, "unit": "nm" },
    "sliding_capacity": { "value": 30, "unit": "nm" },
    "ratio": 1
  }
}
```

`node_a`는 회전 노드입니다. `node_b`는 그와 다른 회전 노드이거나, 접지 브레이크이면 생략하거나 0입니다. `ratio`는 유한하고 0이 아닙니다. 접지에는 1이 필요합니다. 정지 용량은 슬립 용량 이상이고, 둘 다 포트 A에서의 유한한 비음수 토크입니다. `initial_input`은 `[0,1]`의 명시적 체결 분율이며 두 용량을 모두 스케일합니다. 선택적 입력 채널은 정확한 외부 틱 경계에서 체결을 바꿉니다. `heat_node`를 생략하거나 0이면 열은 외부 방출 장부로 갑니다. 공급된 싱크는 열 노드여야 합니다. 온도는 이 용량을 바꾸지 않습니다.

Core 팩토리는 `ComponentDefinition.Clutch(id, a, b, staticCapacity, slidingCapacity, channel, engagement, ratio, heat)`입니다. 그 `Friction` 기술자에는 두 개의 명시적 토크량이 들어 있습니다. 컴파일된 모델은 매개변수를 복사하고, 안정 ID로 정렬하며, 클러치가 있을 때만 지문 태그 8을 더합니다. 각 클러치 단계는 기존의 64 상태 한도에 포함됩니다. 더 이전 모델은 지문과 리플레이 해시를 유지합니다. 결합 충실도 이름은 `hybrid_clutch_powertrain`이고, 교정 상태는 여전히 `unverified`입니다.

| 필드 | 단위 | 의미 |
|---|---|---|
| `slip_speed` | rad/s | 현재의 `omega_A - ratio*omega_B` |
| `clutch_mode` | StateCode | 마지막으로 수용된 구간의 단계: 0 해제, 1 잠김, 2 양의 슬립, 3 음의 슬립 |
| `torque` | Nm | 마지막으로 완료된 외부 틱 동안 A에서의 평균 반력 |
| `heat_flow` | W | 그 틱 동안 생성된 평균 마찰 동력 |
| `friction_heat` | J | 목적지와 상관없이 누적된 생성 열 |

초기 토크/동력/열은 0입니다. 초기 단계는 부하 반력을 풀기 전에, 체결과 상대 속도에서 추론합니다. 단계는 풀이된 구간을 나타내므로, 끝점에 정확히 도착한 상태는 다음 풀이까지 접근 중인 단계를 보일 수 있습니다. 경계 입력은 입력 상태를 즉시 바꾸고, 앞선 구간의 출력 이력을 다시 쓰지 않습니다. `Step` 호출의 끝에서 일어나는 입력 이벤트에도 같습니다. 토크와 동력의 평균에는 수용된 모든 내부 구간이 들어갑니다.

## 결합 적분과 이벤트

`g = omega_A - r*omega_B`에 대해 포트 토크는 `tau_A = tau`, `tau_B = -r*tau`입니다. 제거되는 기계 동력은 `-tau*g`입니다. 이 부호 규약은 `r`의 어느 부호에서나 성립합니다. 해제는 토크를 0으로 둡니다. 슬립은 슬립에 반대하는 운동 용량을 씁니다. 잠긴 클러치는 정적 용량으로 제한된 반력과 함께, 중점 상대 속도를 0으로 둡니다. 이렇게 하면 인공 댐퍼나 뻣뻣한 페널티 스프링을 넣지 않고도 이상적인 잠금 일이 0이 됩니다.

각 내부 구간은 기존의 암시적 중점 전기기계 방정식과 보존적인 실린더 압력 일 풀이를 씁니다. 클러치 힘 응답은 같은 결합 선형 인자에서 얻습니다. 사영된 가우스–자이델 풀이가 유계 정적 반력을 정하는 동안, 실린더 토크는 현재 힘에 대해 다시 계산됩니다. 필요한 운동이 속도 허용 오차를 넘으면 포화된 정적 제약이 풀립니다. 다른 제약이 이탈 방향을 바꾸면 활성 집합을 다시 봅니다. 중복 클러치 루프는 허용됩니다. 개별 반력은 유일하지 않을 수 있습니다. 안정된 컴포넌트 순서가 결정적 배분을 고르고, 검사는 그 결과의 운동, 용량 한계, 총 운동량, 에너지를 확인합니다.

슬립 구간이 상대 속도를 뒤집으면, 유계 이분법이 관측된 슬립 0 경계를 찾고 완전한 상태 복사본에서 그 구간을 다시 재생합니다. 다음 구간은 고착하거나, 반대의 운동 반력으로 이탈합니다. 후보 지속 시간마다 동역학, 열 인자, 실린더 힘 응답을 다시 계산합니다. 가변 인자는 모두 개별 시뮬레이션에 속합니다. 컴파일된 모델은 불변으로 남습니다.

제약 허용 오차는 `2e-13 + 32*epsilon*(abs(omega_A)+abs(r*omega_B))` rad/s이고, `epsilon = 2.2204460492503131e-16`입니다. 포획은 그 허용 오차의 16배 이내 근을 수용합니다. 유한 슬립을 사영해 없애거나 유한 운동 에너지를 버리지 않습니다. 구간의 토크×속도 허용 오차의 두 배 이내에 있는 아주 작은 음의 마찰 일은 0으로 클램프합니다. 더 큰 음의 일은 실패합니다. 보존 검사에는 이 반올림 효과가 포함됩니다. 근 허용 오차 안의 잔차가 두 번째 가짜 이벤트를 만들 수는 없습니다.

풀이는 외부 틱마다 내부 구간을 최대 32개, 근 반복을 56회, 활성 집합마다 제약 반복을 256회, 활성 집합 시도를 `2*clutch_count+2`회까지 허용합니다. 비유한 인자, 수렴하지 않은 제약, 해결되지 않은 이벤트, 소진된 예산, 또는 기존의 실린더/가스 한계는 `NumericalFailure`를 반환합니다. 유계 제약/근 작업 동안 취소를 확인합니다. 외부 틱을 줄이고 관성/변속비 척도, 중복 제약, 용량 스케줄을 검사하세요. 실패한 호출을 부분적으로 완료된 체결로 해석하지 마세요.

생성 열은 `-duration*tau*g_mid`로 적분한 뒤 열 풀이나 외부 열 장부에 더합니다. 수용된 구간의 소스 일, 가스 수송, 화학 이력, 벽 교환, 열 방출은 모두 기존 에너지 회계에 들어갑니다. 클러치 단계, 평균 출력, 누적 열, 보정된 열 합은 물리 상태와 함께 복사되고 해시됩니다. 실패하거나 취소된 다중 틱 호출은 예정된 입력, 단계, 열을 포함해 시작 상태 전체를 복원합니다. 분기는 컴파일된 모델 데이터만 공유합니다. 외부 시간은 유계 정수 나노초 수로 남습니다. 내부 이벤트 지속 시간은 외부에서 보이는 분수 틱을 만들지 않습니다.

비선형 브레이크어웨이 검사는 구간 평균 토크 요구를 씁니다. 변하는 정적 부하가 용량을 처음 넘는 연속 시간의 정확한 순간을 찾지는 않습니다. 마찬가지로 이벤트 괄호는 이산 중점 궤적에 관한 것입니다. 큰 틱은 끝점이 반전을 가리는 빠른 물리 진동을 놓칠 수 있습니다. 전환 주변의 시간을 세밀하게 하고 출력을 비교하세요. 매끄러운 전기기계 동역학은 중점 정확도를 유지하고, 열/벽 결합은 1차로 남으며, 모든 전환 궤적에 대한 보편적인 2차 주장은 하지 않습니다.

## 실험실과 증거

[점화 클러치 실험실](../assets/labs/fired-clutch.power.json)은 예혼합 실린더를 별도의 관성 부하와 클러치 열 노드에 연결합니다. 정확한 틱의 이벤트 여섯 개가 부분/완전 체결, 부하 토크, 해제, 재체결을 적용합니다. 매개변수는 합성값입니다. 0.6초에 걸쳐 현재 Linux 보고서는 다음을 기록합니다.

| 양 | 결과 |
|---|---|
| 엔진/부하 최종 속도 | 68.58488546 rad/s |
| 부하와 실린더 배압을 포함한 순 외부 소스 일 | -96.74607609 J |
| 생성된 클러치 열 | 191.55570747 J |
| 클러치 열 노드 최종 온도 | 300.95777854 K |
| 방출된 연료 열 | 1,630.91064291 J |
| 최종 슬립 | 2.84e-14 rad/s, 잠김 단계 |
| 최종 에너지 잔차 | 1.79e-10 J |
| 모델 지문 / 최종 상태 해시 | `197be44884deee90` / `28bf5335d8e35cde` |

보고서 경계 67개가 모두 대체 배치 크기, 이식 가능한 재생, 실제 MCP 자식 서버 리플레이와 일치합니다. 보고서는 `artifacts/reports/fired-clutch.json`입니다. `name: "fired-clutch"`로 `get_example_model`을 요청하거나 다음을 실행하세요.

```sh
dotnet src/Power.Cli/bin/Release/net10.0/Power.Cli.dll assets/labs/fired-clutch.power.json --output artifacts/reports/fired-clutch.json
```

Core 검사는 부호 있는 변속비와 두 열 목적지를 포함해, 체결, 제동, 반전을 `ClutchPair`와 비교합니다. 잠긴 RL 모터는 해석적으로 합친 관성을 가진 모델과 일치합니다. 잠긴 반응 가스 실린더도 압력과 연료 소비를 포함해, 독립적인 등가 관성 모델과 일치합니다. 스프링/브레이크 진동자는 세 번의 반전과, 포획되는 네 번째 전환점을 지나는 해석적 조각 사인 운동과 일치하며, 세밀화는 반분할마다 오차를 3.7배보다 더 줄입니다. 클러치 세 개의 루프는 중복 제약과 동시 체결을 다룹니다. 검사에는 성공한 가열/포획 접두 뒤의 완전한 롤백, 취소, 정확한 예정 리플레이, 불변 소유권, 분기 독립성, 반복되는 내부 반전 이벤트를 포함한 무할당 동작도 포함됩니다.

자산 v10은 명시적 용량과 모든 채널을 왕복으로 보존합니다. 잘못된 개수, 누락, 중복, 종류가 틀린 레코드, 틀린 단위, 유효하지 않은 한계, 위조된 다운그레이드는 거부됩니다. 진본 v6 점화 실린더 픽스처는 다이제스트, 지문, 업그레이드된 리플레이를 유지합니다. 엄격한 JSON과 에이전트 검사는 성공한 실행과 KPI 통과를 구분합니다. [VALIDATION.ko.md](VALIDATION.ko.md)를 참고하세요.

빌드는 `FiredClutch.powerasset`을 내보냅니다. Studio는 개략적인 클러치 플레이트 두 개, 단계 색, 이름이 있는 단계 출력을 체결 컨트롤 및 열 채널과 함께 준비합니다. 가져오기와 Play 수명 주기 검사가 준비되어 있습니다. 실제 Unity 편집기, 렌더링, Play Mode, IL2CPP 증거는 아직 남아 있습니다. .NET에서 호스트하는 Standard 어셈블리 검사가 그것을 대신하지는 않습니다.

## 영구 기어 결합

[이상 기어와 유성 제약](GEAR_NETWORK.ko.md)은 이제 자유 중점과 클러치/실린더 힘 응답을 같은 영구 제약 공간으로 사영합니다. 점화 유성 실험실은 링 브레이크와 선/링 클러치를 이상 유성 및 종감속과 결합해, 상단 변속과 하단 변속을 리플레이합니다. 상대 속도가 이미 영구적으로 제약된 클러치는 정의되지 않은 독립 반력으로 거부됩니다. 그 밖의 클러치 상태, 용량, 열, 이벤트 계약은 바뀌지 않습니다.
