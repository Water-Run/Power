# 기계식 스풀 계량과 압력 조절

[English](HYDRAULIC_SPOOL.md) · [简体中文](HYDRAULIC_SPOOL.zh-CN.md) · [Français](HYDRAULIC_SPOOL.fr.md) · [Русский](HYDRAULIC_SPOOL.ru.md) · [日本語](HYDRAULIC_SPOOL.ja.md) · **한국어** · [Deutsch](HYDRAULIC_SPOOL.de.md) · [Español](HYDRAULIC_SPOOL.es.md) · [Italiano](HYDRAULIC_SPOOL.it.md) · [Português](HYDRAULIC_SPOOL.pt-BR.md)

`hydraulic_spool_valve`는 명시적 `hydraulic_piston`의 실제 변위로 유압 포트를 계량합니다. 피스톤은 질량, 배제 유체 체적, 압력 힘, 컴플라이언트한 행정 끝을 공급합니다. 별도의 `linear_spring`이 복귀력, 예압, 감쇠를 공급합니다. 여러 계량 랜드가 같은 피스톤을 참조할 수 있습니다.

## 방정식과 경계

닫힘 위치와 완전 개방 위치가 부호 있는 이동 L을 정의합니다. 변위 x에 대해:

```text
opening = clamp((x - closed_position) / L, 0, 1)
d       = pA - pB
Q       = K * opening * d / (d*d + transition_pressure*transition_pressure)^(1/4)
loss    = Q * d >= 0
```

K는 m3/(s*sqrt(Pa)) 단위의 명시적 완전 개방 계수입니다. 전이 압력은 양수입니다. 구현은 큰 압력 차를 제곱하지 않도록 분모를 스케일합니다. 부호 있는 이동은 두 개방 방향을 모두 지원합니다. 닫힌 랜드는 정확히 밀봉됩니다. 누출에는 명시적인 추가 경로가 필요합니다. 포화되는 것은 개방뿐입니다. 위치, 압력, 속도, 저장 에너지는 클램프되지 않습니다.

랜드는 압력 평형이며, 축 방향 제트력은 무시합니다. 계량 포트의 압력 차가 피스톤에 추가 축 방향 힘을 가하지는 않습니다. 명시적 액추에이터의 전/후 챔버 압력이 구동력을 제공합니다. 교축 열과 피스톤/스프링 일은 기존의 보존 장부를 씁니다. 이 모델은 씰 마찰, 유동력 운동량 효과, 캐비테이션, 마모, 온도 의존 형상/점도를 제외합니다. 교정된 밸브가 아니라 선언된 연구용 축소입니다.

[MathWorks Spool Orifice (IL)](https://www.mathworks.com/help/hydro/ref/spoolorificeil.html)은 가변 개방 면적과 별도의 축 방향 유동력 옵션을 문서화합니다. Power!는 자체 정규화 선형 랜드와 기존의 수동 교축 법칙을 씁니다. 형상, 유체 물성 기본값, 구현 코드는 복사하지 않았습니다.

## 공유 풀이와 계약

밸브는 유체 압력, 피스톤 힘, 기계 제약과 같은 결합 뉴턴 풀이에서 `x_old + dx/2`를 읽습니다. 해석 미분에는 압력과 랜드 변위가 모두 포함됩니다. 계량 이동 안에서는 `dOpening/dx=1/L`이고, 밖에서는 미분이 0입니다. 각 끝점에서 야코비안은 평균 편측 기울기를 씁니다. 이것은 지연된 개방 명령이 아니라 동시의 피드백 루프를 유지합니다.

| 매개변수 | 의미 |
|---|---|
| `piston_component` | 명시적 유압 피스톤의 안정 ID |
| `closed_position`, `full_open_position` | m 또는 mm의 서로 다른 위치. 둘 다 피스톤의 공칭 행정 안 |
| `coefficient` | `m3_s_sqrt_pa` 단위의 비음수 완전 개방 계수 |
| `transition_pressure` | Pa 또는 bar의 양의 정규화 압력 |
| `reservoir_pressure` | 유압 B가 생략되었거나 0일 때 필요한 게이지 압력 경계 |

유압 A/B 포트와 선택적 열 싱크는 교축 계약을 따릅니다. 밸브에는 `input_channel`이나 `initial_input`이 없습니다. `opening` 채널을 관측하고 실제 액추에이터 회로를 명령하세요. 평균 유량/동력과 누적 유압 열을 관측할 수 있습니다. 단위, 참조된 컴포넌트 종류, 행정 한계는 조치할 수 있는 검증 오류를 냅니다. 보통의 배치 전체 롤백, 취소, 분기, 정수 시계, 같은 런타임의 정확한 리플레이 계약에 모든 상태와 이력이 포함됩니다. 기존의 물리 모델 지문은 바뀌지 않습니다.

자산 v15는 32바이트 계량 형상 레코드를 더합니다. JSON, CLI, MCP는 같은 정의를 유지합니다. `get_example_model("spool-regulated-pump")`는 전기 펌프, 기계적으로 지배되는 바이패스, 예정된 압력 클러치 충전/배출을 보여 줍니다. 200 N의 정적 닫힘 예압은 1 mm 압축의 200 kN/m 리턴 스프링과 명시적 1000 mm2 액추에이터 면적에서 옵니다. 회전 구동/브레이크는 2 N*m입니다. 3초 실험은 더 낮은 압력의 클러치가 포획될 시간을 남깁니다. 매개변수는 합성값이며 검증되지 않았습니다.

## 증거와 성능

검사는 부호 있는 계량 이동, 수동 양방향 유동, 해석적 압력/위치 미분, 독립적인 정상 압력 근, 별도의 3상태 RK4 과도, 매끄러운 2차 세밀화, 랜드 개방을 지나는 감소하는 오차, 유한 포트 균등화, 배제 체적, 독립적인 운동/유체 에너지, 완전한 트랜잭션을 다룹니다. 워밍업된 진행과 스냅샷 읽기는 관리형 바이트를 0개 할당합니다. 랜드 기울기와 뉴턴/LU 버퍼는 각 시뮬레이션에 속합니다. 새로운 시계나 워커는 더하지 않습니다.

측정 오차, 런타임 범위, 경과 시간은 [VALIDATION.ko.md](VALIDATION.ko.md)를 참고하세요. Studio 밸브/액추에이터 보기와 가져오기/Play 검사는 C# 9 소스로 준비되어 있습니다. 실제 Unity 편집기와 Player 증거는 아직 남아 있습니다.
