# 有限液体燃料フィルムと蒸発

[English](FUEL_FILM.md) · [简体中文](FUEL_FILM.zh-CN.md) · [Français](FUEL_FILM.fr.md) · [Русский](FUEL_FILM.ru.md) · **日本語** · [한국어](FUEL_FILM.ko.md) · [Deutsch](FUEL_FILM.de.md) · [Español](FUEL_FILM.es.md) · [Italiano](FUEL_FILM.it.md) · [Português](FUEL_FILM.pt-BR.md)

`fuel_film` は、追跡されたガス受け側のそばに、明示的な初期液体在庫を格納します。有限な熱ノードが、顕熱と相変化の熱を供給します。蒸発した燃料は、受け側の質量、内部エネルギー、燃料成分に加わります。既存の予混合反応が消費するのは蒸気だけです。液体在庫は初期の濡れであり、噴射された燃料ではなく、総質量と化学エネルギーの台帳の一部のままです。

これは、液体の排除体積が無視でき、飽和温度が規定された、一定物性の研究モデルです。液体レール、ニードル、噴霧の動力学、圧力依存の相平衡、凝縮、多成分燃料物性、キャリブレーション済みのガソリン挙動は実装しません。

## 相エネルギーと有限な熱源

`c_l` を液体の比熱、`c_v` を受け側ガスの等容熱容量、`T_s` を宣言された飽和温度、`L_u > 0` を `T_s` における蒸気と液体の比内部エネルギー差とします。共有される熱の基準は次のとおりです。

```text
e_offset = (c_v - c_l) T_s - L_u
U_liquid = m_liquid (c_l T_liquid + e_offset)
U_vapor_added = delta_m c_v T_s
```

`L_u` は J/kg の内部エネルギー差であり、蒸発のエンタルピーではありません。供給されたエンタルピーをここで使うには、明示的で根拠のある変換が必要です。この基準の下では、液体の熱エネルギーは負になり得ます。温度と質量は、なお物理的に許容できる必要があります。化学エネルギー `m_liquid * LHV` は別であり、反応熱や外部源仕事を作らずに蒸気とともに移ります。

飽和より下では、コンダクタンス `K` が液体容量 `m_liquid c_l` を有限な壁容量 `C_w` へ結合します。温度差は、速度 `K (1 / (m_liquid c_l) + 1 / C_w)` で解析的に減衰します。容量で重み付けした平均温度は一定のままです。液体が `T_s` に達すると、その法則はその時刻を解き、残りの区間を蒸発に使います。

飽和で `T_wall > T_s` のとき、壁の過熱は速度 `K / C_w` で減衰します。区間 `h` で利用できる相熱は `C_w (T_wall - T_s) (1 - exp(-K h / C_w))` で、`m_liquid L_u` で頭打ちになります。フィルムは乾くまで `T_s` のままです。蒸発質量は相熱を `L_u` で割ったものです。ドライアウトは液体の質量とエネルギーをちょうどゼロにして残し、熱の引き出しを止めます。冷たい壁は既存の液体を冷やせます。受け側の蒸気を凝縮することはありません。

すべての輸送は `delta U_liquid + U_vapor_added = Q_from_wall` を満たします。壁は同じ熱を失うので、相変化は外部のエネルギー境界を導入しません。非負の燃料在庫と完全な成分台帳は、総エネルギー台帳とは独立に検査されます。

## グラフとドキュメントの契約

| データ | 要件 |
|---|---|
| `node_a` | 明示的な予混合燃料追跡と LHV を持つ有限ガス受け側 |
| `node_b` | 正の容量と温度を持つ有限な熱壁 |
| `initial_mass` | 非負の kg。完全な初期液体在庫 |
| `initial_temperature` | 正の K。飽和以下 |
| `liquid_specific_heat` | 正の J/(kg K)。JSON 単位 `j_kg_k` |
| `saturation_temperature` | 正の K。JSON 単位 `k` |
| `latent_internal_energy` | 正の J/kg。JSON 単位 `j_kg` |
| `conductance` | 非負の W/K。JSON 単位 `w_k` |

JSON は 6 つのパラメーターをすべて必要とします。フィルムに入力チャンネル、クランクタイミング、別のヒートシンクはありません。無関係なパラメーター、誤ったポート領域、単位、非有限値、サポートされない状態容量は拒否されます。Core の呼び出し側は `ComponentDefinition.LiquidFilm` と `FuelFilmDefinition` を使います。独立した `EquilibriumFuelFilm` 則が、許容状態の作成と有限浴の前進を公開します。

各フィルムは、コンパイラの有界な状態予算へ、報告される状態エントリを五つ寄与します。質量、熱エネルギー、蒸発履歴、平均流量、壁面熱、およびそれらの補償履歴は、シミュレーションが所有します。キャンセル、拒否された入力、遅いソルバー失敗、独立した分岐、投機的なクラッチ区間は、完全なトランザクションを保持します。成功したステッピングとスナップショット読み取りは、ウォームアップの後、マネージドメモリを割り当てません。

## 積分の精度

受理された区間は、フィルム / ガス / 機構と反応 / ガス / フィルムの半ステップを使います。壁を共有するフィルムは、ガス前進の前に安定したコンポーネント順で走り、その後は逆順です。有限な壁温度はフィルムのサブステップ間で運ばれ、壁面熱は同じ熱求解に入ります。

孤立した有限浴の法則は、顕熱加熱、飽和、ドライアウトにわたって解析的です。独立した同時 ODE 積分が、壁を共有する二つのフィルムと、他の壁面熱源なしでチョークしたガス出口を通して輸送される蒸気について、2 次の滑らかな細分化を検証します。ガス熱リンクとその他の熱源は、引き続き明示的な外側区間の壁温度を読むため、その結合は 1 次精度を保ちます。反応ウィンドウ、バルブイベント、ドライアウトは、それ自身の細分化検査を必要とします。正確なバッチリプレイだけでは、時間刻み精度や、燃焼パワートレインに対する一様な 2 次は証明されません。

## 観測量と移植可能な意味論

| フィルムフィールド | 意味 |
|---|---|
| `mass` | 残る液体燃料、kg |
| `temperature` | 液体温度。乾いているときは宣言された飽和温度 |
| `internal_energy` | 宣言された相基準の下での、符号付き液体熱エネルギー、J |
| `chemical_energy` | 残る液体燃料の化学エネルギー、J |
| `evaporated_fuel_mass` | 累積で供給された蒸気、kg |
| `mass_flow` | 最後の完了した物理ティックにわたる平均蒸気供給、kg/s |
| `film_wall_heat` | 壁から引き出された累積熱、J。冷却で負になり得る |
| `heat_flow` | 瞬間の `K (T_wall - T_liquid)`、W。乾いているときはゼロ |

出力 ID と単位は、検証またはセッション作成を通して発見してください。大域の質量、燃料、化学エネルギーの観測量は、フィルム在庫を含みます。内部の蒸気供給は、リザーバーの燃料エネルギーや外部エンタルピーを増やしません。

アセット v19 はすべての相物性を格納し、v1-v18 リーダーを保持します。各フィルムは、型付きの 64 バイト相レコードを一つ必要とします。有界な長さ/個数、ダイジェスト、完全な被覆、重複/欠落レコード、単位、物理コンパイル、ダウングレード保護が検査されます。本物の v17 燃料計量フィクスチャは、フィンガープリントと、同じランタイムでのアップグレードされたリプレイを保ちます。[ASSET_FORMAT.ja.md](ASSET_FORMAT.ja.md) を参照してください。

## ラボラトリーと残る作業

`film-fired-cylinder` は、初期に濡れたフィルムを加熱し、空気を別に導入し、その後、利用できる蒸気を規定 Wiebe 燃焼で消費します。有限な高温壁が相熱を支払います。液体は直接燃焼しません。JSON、CLI、移植可能なリプレイ、実際の MCP サーバーは、すべてのレポート境界で一致します。ソース、スキーマ、セッションの契約は共有されたままです。パラメーターは `unverified` です。

測定された数値エビデンスは [VALIDATION.ja.md](VALIDATION.ja.md) を参照してください。用意された Unity のフィルムマーカーとライフサイクル検査は、なお実際のエディター/Play 検証を必要とします。別の[液体インジェクター](LIQUID_FUEL_INJECTION.ja.md)が、有限で柔軟な源からフィルムを補給するようになりました。ポンプ/補給、ニードル/噴霧、実測の燃料物性、点火/ECU、完全な吸気/排気挙動、トランスミッション制御、キャリブレーション済みパワートレインは、別の要件のままです。
